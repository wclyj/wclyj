# Linux 下查看文件和目录占用的空间

## 前言

镜像目录涨到数 GB 时，先分清是整块盘满了，还是某个目录在涨。两条命令一起用：

- `df` 看挂载点的容量、已用和使用率，不回答哪个文件大
- `du` 从目录往下加总实际占用的块

## 查看文件磁盘使用情况

`-h` 把字节换成 K、M、G：

```bash
df -h
```

示意：`/dev/vdb1` 为 80G、已用 61G、挂在 `/var/lib/docker`。这块盘到了八成，就进它继续看。

只列下一层，避免一次打出整棵树：

```bash
du -h -d 1 /var/lib/docker
```

示意里 `overlay2` 约占 48G，卷约占 12G。对最大的那一层再执行一次 `-d 1`，确认无用内容后再删。`du` 加总的是文件占用，和 `df` 的剩余块有时对不齐；删完若空间没回来，再查是否还有进程握着已删除文件。

# Kibana 与 Elasticsearch 配套

## 版本对齐

两边要使用同一主版本。版本错开时，控制台可能打不开，索引模式也建不起来。安装前先核对发行号。

## 改语言

解压后编辑 `config/kibana.yml`。界面文案、日期和数字格式由下面这项决定：

```yaml
i18n.locale: "zh-CN"
```

它不改集群里的文档。若搜索服务不在本机默认端口，同一文件里还要改成实际节点地址。

## 启动

保存后到 `bin` 执行启动脚本：Windows 用 `kibana.bat`，类 Unix 执行 `kibana`。就绪后访问本机 `5601` 端口。首次进入会检查能否连上搜索服务，连通后即可建索引模式并筛选字段。页面停在无法连接时，先看搜索进程是否在听、版本是否一致、配置里的节点地址有没有写错。

# 七天用 Go 实现 Web 框架 Gee

Gee 是一个从零开始、按天叠加的迷你 Web 框架。它不依赖现成路由库，而是直接实现 `http.Handler`，用自己的代码接住每一个请求。

第一天通常只做三件事：定义处理函数类型、用一张表记下“方法 + 路径”到处理函数的映射、在 `ServeHTTP` 里查表并调用。第二天把 `http.ResponseWriter` 和 `*http.Request` 包进 `Context`，让处理函数用 `Query`、`JSON`、`HTML` 这类方法，而不是每次手写响应头和状态码。后面几天再往上加动态路由、分组、中间件和模板。

读这组笔记时，重点不是背 API，而是看一次请求怎样从监听端口走进路由表，再走进上下文，最后写回响应。自己敲一遍，比只看成品框架更容易明白中间件和参数是挂在哪一层的。

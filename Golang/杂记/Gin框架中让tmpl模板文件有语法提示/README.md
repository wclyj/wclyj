# Gin框架中让tmpl模板文件有语法提示

## 前言

Gin 常用 `.tmpl` 作为模板后缀。新建这种文件时，编辑器往往找不到对应的文件类型，于是把它当成普通文本：没有标签高亮，也没有成对括号提示。模板里既有 HTML，又夹着 Go 模板动作，写起来很容易漏掉闭合标签。

## 解决方法

`.tmpl` 的主体仍是 HTML。数据位置写成双花括号动作，例如 `{{.title}}`，这和普通 HTML 的差别只在动作语法，不在文档结构。因此可以把该后缀交给 HTML 的语法分析。

在 GoLand 中打开设置，进入 Editor → File Types，在左侧选中 HTML。右侧的文件名模式列表里新增一条 `*.tmpl`，保存后重新打开模板文件。编辑器就会按 HTML 着色标签、属性和注释；双花括号里的动作仍然是普通文本，但周围的结构已经能被检查。

若项目里同时存在 `.html` 与 `.tmpl`，两条模式可以并存，互不影响。改完后新建一个只含标题和 `{{.name}}` 的模板，确认标签有颜色、属性有补全，即说明映射生效。

# Go Web开发教程

这一组笔记围绕用 Go 写 Web 服务展开，主线是 Gin。浏览器或客户端发出 HTTP 请求，服务端按路径和方法找到处理函数，再把 HTML、JSON 或其他正文写回响应。标准库的 `net/http` 已经能完成这条链路，但路由分组、参数绑定、模板渲染和中间件都要自己拼装。

Gin 把这些重复工作收成一套轻量 API：`gin.Default()` 建好引擎，`GET` / `POST` 等方法登记路由，`*gin.Context` 同时携带请求和响应。后面的笔记会先用标准库摸清请求与响应，再转到 Gin 的安装、REST 风格接口、渲染、参数、上传、重定向、路由组和中间件。数据库访问则交给 GORM，把结构体和表对应起来。

学习时建议按文件夹顺序走：先跑通一个最小服务，再逐项替换成 Gin 的写法，最后把接口、模板和数据库串成一个小项目。

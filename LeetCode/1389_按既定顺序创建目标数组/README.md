# 按既定顺序创建目标数组

给出数值数组 `nums` 和同样长度的下标数组 `index`。目标数组起初为空。从左到右，把 `nums[i]` 插到目标数组的下标 `index[i]` 处（插入，不是覆盖）。题目保证每次插入位置都合法。返回最终数组。

## 思路

按顺序做插入即可。插入会把该位置及其右边的元素整体右移，所以先插入和后插入的同一下标含义不同：后写的数会挤到更左边，早先的数被推到右边。

## 演算

`nums = [7, 8, 9]`，`index = [0, 0, 1]`。

- 把 7 插到空数组的 0 号位 → `[7]`。
- 把 8 插到 0 号位，原来的 7 右移 → `[8, 7]`。
- 把 9 插到 1 号位，7 再右移 → `[8, 9, 7]`。

## 代码

```python
class Solution:
    def createTargetArray(self, nums, index):
        built = []
        for value, pos in zip(nums, index):
            built.insert(pos, value)
        return built
```

## 复杂度

每次插入最坏要移动当前全部元素。长度为 `n` 时，时间 `O(n^2)`，空间 `O(n)`。题目的 `n` 不超过 100，平方可以接受。

## 边界

只有一个元素且下标为 0 时，结果就是单元素列表。插入下标等于当前长度时，相当于追加到末尾，不会越界。不要用赋值覆盖，否则长度不会增长。

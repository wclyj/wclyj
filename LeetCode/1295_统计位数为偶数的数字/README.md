# 统计位数为偶数的数字

给定非负整数数组，数一数有多少个数的十进制位数是偶数。例如 10 有两位，算进去；7 只有一位，不算。

## 思路

对每个数反复除以 10，数能除多少次，就是位数。位数模 2 等于 0 则计数加一。转成字符串再看长度也能做，但除法不依赖语言的字符串实现，也避免把符号或小数点算进去。

## 演算

`nums = [10, 7, 100, 88, 5]`。

| 数 | 除法过程 | 位数 | 是否偶数位 |
| --- | --- | --- | --- |
| 10 | 10→1→0 | 2 | 是 |
| 7 | 7→0 | 1 | 否 |
| 100 | 100→10→1→0 | 3 | 否 |
| 88 | 88→8→0 | 2 | 是 |
| 5 | 5→0 | 1 | 否 |

答案是 2。

## 代码

```python
class Solution:
    def findNumbers(self, nums):
        even_cnt = 0
        for num in nums:
            width = 0
            rest = num
            # 0 本身是一位，下面单独处理，避免除不尽次
            if rest == 0:
                width = 1
            while rest:
                width += 1
                rest //= 10
            if width % 2 == 0:
                even_cnt += 1
        return even_cnt
```

## 复杂度

每个数最多大约 `log10(num)` 次除法。设数组长度为 `n`、最大值位数为 `d`，时间 `O(n * d)`，空间 `O(1)`。

## 边界

`0` 的位数是 1，不是 0。若写成 `while num` 却不特判，0 会被当成 0 位，偶数位判断会错。题目若保证正整数，特判也不影响正确性。

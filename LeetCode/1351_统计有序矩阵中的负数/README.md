# 统计有序矩阵中的负数

矩阵每一行从左到右不上升，每一列从上到下也不上升。统计其中负数的个数。

## 思路

因为一行内部已经排好，负数一定连成最右边的一段。对每一行二分，找到第一个小于 0 的下标，这一行的负数个数就是「列数减去该下标」。各行相加。

还可以从左下角走阶梯：当前格若是负的，它右边整段都是负的，可以整段计入并上移；若非负，则向右找。这样整体是 `O(行数 + 列数)`。下面给出二分写法，更直观。

## 演算

```
5   1  -2
3  -4  -6
0  -1  -8
```

- 第一行第一个负数在下标 2，负数 1 个。
- 第二行第一个负数在下标 1，负数 2 个。
- 第三行第一个负数在下标 1，负数 2 个。

合计 5。注意第三行开头的 0 不是负数，不能把整行都算进去。

## 代码

```python
class Solution:
    def countNegatives(self, grid):
        cols = len(grid[0])
        total = 0
        for row in grid:
            lo, hi = 0, cols
            while lo < hi:
                mid = (lo + hi) // 2
                if row[mid] < 0:
                    hi = mid
                else:
                    lo = mid + 1
            # lo 是本行第一个负数的位置；若没有负数，lo == cols
            total += cols - lo
        return total
```

## 复杂度

`m` 行、`n` 列时，每行二分，时间 `O(m log n)`，额外空间 `O(1)`。阶梯扫描是 `O(m + n)`。

## 边界

整行都非负时，二分把 `lo` 推到 `cols`，本行贡献 0。整行都是负数时，`lo` 停在 0，贡献整行。单格矩阵 `[[-3]]` 应返回 1，`[[0]]` 应返回 0。

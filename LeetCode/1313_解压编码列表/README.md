# 解压编码列表

压缩数组成对出现：下标偶数位是次数 `freq`，紧随其后的奇数位是数值 `val`。每一对展开成 `freq` 个 `val`，再按原顺序拼成一条新数组。

## 思路

步长为 2 地扫描。读出一对后，把 `val` 重复 `freq` 次接到结果末尾。次数为 0 时这一对不贡献任何元素，但后面的对仍要继续处理。

## 演算

`nums = [2, 5, 1, 8, 3, 0]`。

- 第 0、1 位：5 重复 2 次 → `[5, 5]`。
- 第 2、3 位：8 重复 1 次 → `[5, 5, 8]`。
- 第 4、5 位：0 重复 3 次 → `[5, 5, 8, 0, 0, 0]`。

## 代码

```python
class Solution:
    def decompressRLElist(self, nums):
        plain = []
        pair = 0
        while pair < len(nums):
            times = nums[pair]
            value = nums[pair + 1]
            # 次数为 0 时 extend 空序列，相当于跳过
            plain.extend([value] * times)
            pair += 2
        return plain
```

## 复杂度

设压缩长度为 `n`，展开后长度为 `m`（所有次数之和）。时间 `O(m)`，空间 `O(m)`，输出本身就需要这么多。

## 边界

某一对次数是 0，结果里不应出现占位。题目保证长度为偶数且次数非负，所以不会读到落单的最后一个数。若所有次数都是 0，应返回空列表。

# 访问所有点的最小时间

平面上有若干整数点，必须按数组给出的顺序依次走到。每一秒可以：水平走 1，或竖直走 1，或斜着同时在两个方向各走 1。求走完的最少秒数。

## 思路

从 A 到 B，水平差 `dx`、竖直差 `dy`。斜着走能同时消化两个方向，所以较短的那个差可以被斜步完全覆盖，多出来的差只能直着走。总步数就是 `max(dx, dy)`，也就是切比雪夫距离。点与点之间没有捷径可抄，因为顺序固定，把相邻段加起来即可。

## 演算

点列 `[[0, 0], [2, 1], [2, 5]]`。

- `(0,0) → (2,1)`：`dx = 2`，`dy = 1`，需要 2 秒。例如 `(0,0) → (1,1) → (2,1)`。
- `(2,1) → (2,5)`：`dx = 0`，`dy = 4`，没有斜步可省，需要 4 秒。
- 合计 6 秒。

## 代码

```python
class Solution:
    def minTimeToVisitAllPoints(self, points):
        seconds = 0
        for i in range(1, len(points)):
            dx = abs(points[i][0] - points[i - 1][0])
            dy = abs(points[i][1] - points[i - 1][1])
            # 斜步把较小差值吃掉，剩下的直走
            seconds += dx if dx > dy else dy
        return seconds
```

## 复杂度

只扫相邻点一次，时间 `O(n)`，额外空间 `O(1)`。

## 边界

只有一个点时循环不执行，答案是 0。两点横坐标、纵坐标都相同，差都是 0，贡献也是 0。坐标允许为负，用绝对值即可，不用改公式。

# 数组中的第 K 个最大元素

在未排序数组里找第 `k` 大的元素。这里按排序后的位置计，重复值占多个名次，不是第 `k` 个不同的值。`k` 合法，介于 1 和长度之间。

## 思路

全排序后从末尾倒数第 `k` 个，时间主要花在 `O(n log n)` 的排序上，写起来短，数据量不大时够用。

只要第 `k` 大时，维护一个大小为 `k` 的小根堆更合适：堆顶永远是当前这 `k` 个较大值里最小的那个，也就是第 `k` 大。后面的数若比堆顶大，就替换堆顶。扫完后堆顶即答案。

## 演算

`nums = [7, 1, 9, 4, 9]`，`k = 3`。从大到小是 `9, 9, 7, 4, 1`，第 3 个是 7。两个 9 占掉第一、第二名。

小根堆过程（只保留 3 个）：

- 先放入 7、1、9，堆顶是 1。
- 4 比堆顶大，换入，堆内为 4、7、9，堆顶 4。
- 9 比 4 大，换入，堆内为 7、9、9，堆顶 7。

返回 7。

## 代码

```python
import heapq

class Solution:
    def findKthLargest(self, nums, k):
        # 小根堆里留下目前最大的 k 个数，堆顶即第 k 大
        best = nums[:k]
        heapq.heapify(best)
        for v in nums[k:]:
            if v > best[0]:
                heapq.heapreplace(best, v)
        return best[0]
```

## 复杂度

堆大小为 `k`，每个元素最多调整一次，时间 `O(n log k)`，空间 `O(k)`。全排序是 `O(n log n)` 时间和 `O(n)` 额外空间（若排序要拷贝）。

## 边界

`k = 1` 时堆里只留最大值。`k` 等于长度时，答案是最小值，堆会容纳全部元素。重复数字各自占一个名次，不能先去重再取第 `k` 个。

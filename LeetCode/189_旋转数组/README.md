# 旋转数组

把数组向右旋转 `k` 步：末尾的元素依次移到开头。`k` 是非负整数，可以比长度大。希望尽量原地完成。

## 思路

`k` 先对长度取模，转完整圈等于没转。

三次反转可以原地完成：

1. 整段反转。
2. 反转前 `k` 个，它们就是原来的末尾，反转后恢复原有先后。
3. 反转剩下的后缀，恢复原来前半段的顺序。

另外两种常见写法：用新数组，下标 `(i + k) % n` 接收原 `nums[i]`；或者切片拼接「后 k 个 + 前面剩下的」。切片写法清楚，但会分配新列表。反复把末尾弹出再插到开头也能做，每次插入是线性的，转 `k` 步就是平方时间。

## 演算

`nums = [8, 1, 4, 6, 2]`，`k = 2`。期望结果 `[6, 2, 8, 1, 4]`。

- 整体反转：`[2, 6, 4, 1, 8]`
- 反转前 2 个：`[6, 2, 4, 1, 8]`
- 反转下标 2 到末尾：`[6, 2, 8, 1, 4]`

若 `k = 7`，`7 % 5 = 2`，和转 2 步相同。

## 代码

```python
class Solution:
    def rotate(self, nums, k):
        n = len(nums)
        k %= n
        if k == 0:
            return

        def rev(lo, hi):
            while lo < hi:
                nums[lo], nums[hi] = nums[hi], nums[lo]
                lo += 1
                hi -= 1

        rev(0, n - 1)
        rev(0, k - 1)
        rev(k, n - 1)
```

## 复杂度

三次反转各自线性，合计时间 `O(n)`，只使用若干下标，额外空间 `O(1)`。新数组写法时间同样是 `O(n)`，空间 `O(n)`。

## 边界

`k` 是长度的整数倍时，取模后为 0，数组应保持原样。`k = 0` 同样直接返回。单元素数组取模后 `k` 为 0。反转区间要包含端点，右边界写成 `n - 1` 而不是 `n`。

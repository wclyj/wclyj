# 奇数值单元格的数目

有一张 `n` 行 `m` 列的表，起初每个格子都是 0。`indices` 里每一对 `[ri, ci]` 表示：第 `ri` 行整行加 1，并且第 `ci` 列整列再加 1（行列交点会被加两次）。全部做完后，数一数值为奇数的格子有多少。

## 思路

格子 `(r, c)` 的终值等于「第 r 行被点到的次数 + 第 c 列被点到的次数」。奇偶只看次数的奇偶：一奇一偶才是奇数，两奇或两偶都是偶数。

因此不必真的改整张表。分别统计每一行、每一列被点中的次数，数出奇数行有多少、奇数列有多少。奇数格 = 奇数行 × 偶数列 + 偶数行 × 奇数列。

模拟整表也能做对，但每次操作要扫一行加一列，数据变大时更费。

## 演算

`n = 3`，`m = 2`，`indices = [[0, 0], [2, 1]]`。

行次数：第 0 行 1 次，第 1 行 0 次，第 2 行 1 次。奇数行 2 个，偶数行 1 个。

列次数：第 0 列 1 次，第 1 列 1 次。奇数列 2 个，偶数列 0 个。

奇数格 = `2 * 0 + 1 * 2 = 2`。

手工核对终表：

```
先做 [0,0]：  2 1
              1 0
              1 0
再做 [2,1]：  2 2
              1 1
              2 2
```

只有中间那一行两个 1 是奇数，共 2 个。

## 代码

```python
class Solution:
    def oddCells(self, n, m, indices):
        row_times = [0] * n
        col_times = [0] * m
        for r, c in indices:
            row_times[r] += 1
            col_times[c] += 1
        odd_r = sum(t % 2 for t in row_times)
        odd_c = sum(t % 2 for t in col_times)
        # 奇+偶 才是奇数
        return odd_r * (m - odd_c) + (n - odd_r) * odd_c
```

## 复杂度

设操作条数为 `k`。统计次数 `O(k + n + m)`，空间 `O(n + m)`。模拟写法是 `O(k * (n + m) + n * m)`。

## 边界

同一格被多次点到时，次数相加后再取奇偶，不能把「点过」当成布尔值。`indices` 为空时全是 0，答案是 0。行和列的交点加了两次，公式里已经包含，不用再单独减。

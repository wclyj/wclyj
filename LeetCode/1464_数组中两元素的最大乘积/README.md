# 数组中两元素的最大乘积

从数组里选两个不同下标 `i`、`j`，使 `(nums[i] - 1) * (nums[j] - 1)` 最大，返回这个乘积。题目里每个元素都是正整数。

## 思路

每个数先减 1 再相乘，减 1 是单调的，不改变大小顺序。正整数里挑两个最大的，减 1 后的乘积就是答案。一次扫描同时记下最大值和次大值，不必排序，也不必从原数组里删元素。

## 演算

`nums = [2, 8, 3, 6]`。

从左到右：

- 看到 2：最大 2，次大还没有。
- 看到 8：8 更大，原来的 2 降为次大。
- 看到 3：比次大 2 大，次大改为 3。
- 看到 6：比次大 3 大，次大改为 6。最大仍是 8。

乘积 `(8 - 1) * (6 - 1) = 35`。若误选 8 和 3，只有 `(7) * (2) = 14`，更小。

## 代码

```python
class Solution:
    def maxProduct(self, nums):
        largest = 0
        runner = 0
        for v in nums:
            if v >= largest:
                runner = largest
                largest = v
            elif v > runner:
                runner = v
        return (largest - 1) * (runner - 1)
```

## 复杂度

一次扫描，时间 `O(n)`，额外空间 `O(1)`。

## 边界

数组长度至少为 2。两个元素都是 1 时，乘积是 0。出现两个相同的最大值时，次大也应是这个值，所以更新最大时要把旧的最大挪到次大，不能只覆盖最大。

# 用右侧最大值改写每个位置

把数组里每个位置换成它右边所有数中的最大值。最右那个位置右边没有数，规定写成 -1。要求改完后返回这个数组。

## 思路

右边的最大值只增不减地从右往左传递。维护一个「目前见过的右侧最大」，初值是 -1（最右边的哨兵）。从末尾走到开头：先把当前位置写成这个右侧最大，再用原值去更新它。从左往右做的话，每个位置都要向后扫描，会变成平方时间。

## 演算

原数组 `[9, 3, 8, 2]`。

- 下标 3，原值 2，右边没有数，写成 -1。右侧最大更新为 2。数组变为 `[9, 3, 8, -1]`。
- 下标 2，原值 8，写成 2。8 比 2 大，右侧最大改为 8。数组 `[9, 3, 2, -1]`。
- 下标 1，原值 3，写成 8。3 没有超过 8。数组 `[9, 8, 2, -1]`。
- 下标 0，原值 9，写成 8。

结果 `[8, 8, 2, -1]`。含义：9 的右边最大是 8，3 的右边最大是 8，8 的右边最大是 2，2 的右边为空。

## 代码

```python
class Solution:
    def replaceElements(self, arr):
        right_best = -1
        for i in range(len(arr) - 1, -1, -1):
            original = arr[i]
            arr[i] = right_best
            if original > right_best:
                right_best = original
        return arr
```

## 复杂度

一次从右到左扫描，时间 `O(n)`，原地修改，额外空间 `O(1)`。

## 边界

只有一个元素时，循环把它写成 -1，这是题目要求。若数组里出现比 -1 还小的数，比较时仍用原值更新 `right_best`，不要和已经写进去的 -1 比较。

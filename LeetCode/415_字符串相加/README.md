# 字符串相加

两个字符串表示非负整数，求它们的和，仍以字符串返回。不能把整个字符串直接转成整数，也不能调用大整数库。输入没有前导零，但答案的最高位可能因为进位多出一位。`0` 本身允许作为整个数。

## 思路

从个位向高位对齐，逐位相加，并记住进位。较短的那一边高位当作 0。某一位的和除以 10 是新的进位，余数是这一位的数字。两个指针都走完后，若进位还剩 1，要再补一位。

为避免在列表头部不断插入，先把各位按从低到高存下来，最后整体反转再拼成字符串。

## 演算

`"598" + "47"`。

| 位 | 左 | 右 | 进位进来 | 和 | 写下 | 新进位 |
| --- | --- | --- | --- | --- | --- | --- |
| 个位 | 8 | 7 | 0 | 15 | 5 | 1 |
| 十位 | 9 | 4 | 1 | 14 | 4 | 1 |
| 百位 | 5 | 无 | 1 | 6 | 6 | 0 |

从高位读回去是 `"645"`。

## 代码

```python
class Solution:
    def addStrings(self, num1, num2):
        i = len(num1) - 1
        j = len(num2) - 1
        carry = 0
        low_to_high = []
        while i >= 0 or j >= 0 or carry:
            bit = carry
            if i >= 0:
                bit += ord(num1[i]) - ord("0")
                i -= 1
            if j >= 0:
                bit += ord(num2[j]) - ord("0")
                j -= 1
            low_to_high.append(str(bit % 10))
            carry = bit // 10
        return "".join(reversed(low_to_high))
```

## 复杂度

设两串长度为 `a`、`b`，时间 `O(a + b)`，存放各位的列表同样是这个量级。

## 边界

`"999" + "1"` 应得 `"1000"`，循环条件必须包含剩余进位，否则最高位会丢。`"0" + "0"` 应得 `"0"`，不能写成空串。字符用码点相减得到数字，不要对整串使用 `int()`。

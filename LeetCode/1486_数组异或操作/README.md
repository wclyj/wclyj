# 数组异或操作

给定正整数 `n` 和起点 `start`。先按下标构造数组：`nums[i] = start + 2 * i`，长度就是 `n`。再把这 `n` 个数按位异或，返回结果。

## 思路

异或满足交换律，也满足 `x ^ x = 0`、`x ^ 0 = x`。这里直接按公式生成每一项再折叠异或即可，不必先把数组存下来。`n = 1` 时循环只做一次，结果就是 `start` 自己，不用单独分支。

## 演算

`n = 3`，`start = 1`。

- `i = 0`：`1 + 0 = 1`
- `i = 1`：`1 + 2 = 3`
- `i = 2`：`1 + 4 = 5`

`1 ^ 3 = 2`（二进制 `01 ^ 11 = 10`），`2 ^ 5 = 7`（`010 ^ 101 = 111`）。答案是 7。

## 代码

```python
class Solution:
    def xorOperation(self, n, start):
        folded = 0
        for i in range(n):
            folded ^= start + 2 * i
        return folded
```

## 复杂度

循环 `n` 次，时间 `O(n)`，空间 `O(1)`。

## 边界

`n = 1` 时不应返回 0。初值必须是 0，这样第一项异或进去后保持原样；如果初值设成 `start` 又从 `i = 0` 开始，会把起点异或两次，变成 0。

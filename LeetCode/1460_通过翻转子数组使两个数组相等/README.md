# 颠倒任意连续区间后两数组能否相同

`target` 和 `arr` 等长。每一步可以任选 `arr` 的一段连续区间并整段颠倒，次数不限。问能否把 `arr` 变成 `target`。

## 思路

长度为 2 的颠倒就是交换相邻两项。相邻交换可以排出任意顺序，所以只要两个数组的元素种类和个数完全一致，就一定能变过去；缺了某个数，或者某个数多了一个，就变不成。

因此不必模拟翻转。用计数比较多重集合，或两边排序后逐项对比，结果一样。

## 演算

- `target = [4, 1, 4]`，`arr = [1, 4, 4]`。1 出现一次，4 出现两次，两边相同。可以先把 `arr` 前两位颠倒得到 `[4, 1, 4]`，返回真。
- `target = [2, 0]`，`arr = [2, 1]`。`arr` 里没有 0，怎么颠倒都不会出现 0，返回假。

## 代码

```python
from collections import Counter

class Solution:
    def canBeEqual(self, target, arr):
        # 翻转不改变每个数值出现的次数
        return Counter(target) == Counter(arr)
```

## 复杂度

计数是 `O(n)` 时间、`O(n)` 空间。排序对比是 `O(n log n)` 时间，若原地排序则额外空间更小。

## 边界

两个数组本来就相同，不需要任何翻转，也应返回真。只有一个元素时，相等即真。重复元素必须按次数比较，不能把它们收成集合后丢掉重复。长度为 2 的区间颠倒一次，效果就是交换相邻两项；相邻交换足以生成任意排列，所以计数相同就够了，不必再搜索翻转顺序。

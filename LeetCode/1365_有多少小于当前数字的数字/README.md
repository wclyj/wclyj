# 统计比当前值更小的个数

对数组中每个 `nums[i]`，统计有多少个其他位置的值严格小于它。相等不算。按原下标顺序返回答案。

## 思路

本题数值范围很小（0 到 100），适合计数。先数每个取值出现了几次，再做前缀：位置 `v` 上记下「所有小于 `v` 的数一共有多少」。查询时直接读前缀，相等的值不会被算进去，因为前缀停在 `v` 之前。

暴力两两比较是平方时间。排序后用 `index` 找第一次出现的位置也能做，但每次 `index` 仍是线性扫描，总体不一定更好；计数法在这个值域上是线性的。

## 演算

`nums = [4, 9, 4, 1]`。

频次：1 出现 1 次，4 出现 2 次，9 出现 1 次。

小于该值的个数：

- 小于 1：0
- 小于 4：只有那些 1，共 1
- 小于 9：1 个 1 加上 2 个 4，共 3

按原顺序：`[1, 3, 1, 0]`。两个 4 的答案相同，因为彼此相等，谁也不小于谁。

## 代码

```python
class Solution:
    def smallerNumbersThanCurrent(self, nums):
        freq = [0] * 101
        for v in nums:
            freq[v] += 1
        smaller = [0] * 101
        seen = 0
        for v in range(101):
            smaller[v] = seen
            seen += freq[v]
        return [smaller[v] for v in nums]
```

## 复杂度

值域大小是常数 101。计数与前缀都是 `O(值域 + n)`，即 `O(n)`。空间 `O(1)`（值域固定）加上输出 `O(n)`。

## 边界

全部相等时，每个位置的答案都是 0，例如四个相同的数。值为 0 时，小于它的个数一定是 0。不要把「小于等于」写进前缀，否则重复数字会把自己算进去。

# 一维数组的动态和

动态和的第 `i` 项是原数组从下标 0 加到下标 `i` 的和。返回这条新数组，长度与原数组相同。

## 思路

前缀和。第 0 项就是原数组第 0 项。从第 1 项起，每一项等于「左边已经算好的前缀」加上自己。可以写到新数组，也可以从左到右原地累加，因为用过的左边值已经是前缀，不会再被当作原值。

## 演算

`nums = [4, -1, 5]`。

- 下标 0：4
- 下标 1：`4 + (-1) = 3`
- 下标 2：`3 + 5 = 8`

结果 `[4, 3, 8]`。负数要照加，不能跳过。

## 代码

```python
class Solution:
    def runningSum(self, nums):
        for i in range(1, len(nums)):
            nums[i] = nums[i] + nums[i - 1]
        return nums
```

## 复杂度

一次扫描，时间 `O(n)`。原地写法额外空间 `O(1)`。

## 边界

单元素数组的动态和就是它自己，循环从 1 开始，不会越界。全是 0 时结果仍全是 0。若调用方还要保留原数组，应先拷贝再累加。

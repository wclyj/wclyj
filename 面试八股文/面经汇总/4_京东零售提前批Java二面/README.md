# 京东零售提前批 Java 二面

## 前言

二面大约二十分钟，项目一句带过，重心在启动配置和两个数据结构，最后留一道玻璃杯题目。

## 第二面

- 用一分钟介绍项目里真正上线的功能
- 数据库用哪一种，事务隔离做到哪一级
- 启动类上的组合注解做了什么，配置类上的注解又做了什么
- 自动配置怎样被导入，条件注解怎样决定一个 Bean 出不出现
- 约定大于配置：目录、入口和默认属性可以不写，偏离约定才需要配置
- 配置优先级：命令行和系统属性高于外部文件，主配置与引导配置服务的阶段不同。同名键要能说出谁覆盖谁
- 缩进式配置的好处是层级清楚，缺点是缩进和类型容易写错
- 前端为什么选这一套：团队熟悉、组件够用即可，不要贬低另外两套
- 持久层为什么手写语句而不是用领域仓储：语句可控，复杂查询更直观
- 两种持久化风格：一种自己写语句，一种由对象变化生成语句。后者省事，前者更好优化
- 位图用位表示某个数在不在，省空间，适合去重和布隆过滤器的底层
- 字典树共享前缀，查找代价取决于词长，适合提示和敏感词
- 一百层楼、两只杯子，找最低的碎裂层。二分会在高处连续摔碎，把两次机会很快用光。更稳的是第一只杯子按逐渐缩小的间隔往上试，碎了再用第二只在上一档和这一档之间逐层试。间隔选在二十层附近，最坏次数大约是十四次这一量级

# Optional类

## 概念

Optional 是一层容器：里面要么放着一个值，要么明确标记为空。用它代替直接返回空引用时，调用方要先处理空分支，空指针就不容易在半路抛出。

## 常用方法

- of：入参必须已经非空，否则马上抛出异常
- empty：得到一个确定为空的容器
- ofNullable：入参为空就得到 empty，否则包住这个值
- isPresent：询问里面有没有值
- orElse：有值就取出，没有就返回事先准备好的替补
- orElseGet：没有值时才执行供给函数，替补的计算可以推迟
- map：有值就做一次映射并重新包装，没有就仍返回空容器
- flatMap：映射函数自己必须返回 Optional，避免容器再套一层

# StackNet 是多层的栈式集成

普通的两层栈式融合，是先训练若干基模型，再拿它们的预测当新特征，交给一个元模型。StackNet 把这个主意做成可叠很多层的网络：每一层含有多个模型，层与层之间传递的是预测值（或各类概率），而不是原始特征的简单拷贝。层数增加以后，它在形式上像神经网络，但每一「神经元」是一整份传统学习器，例如树、线性模型或核方法。

作者给出的实现把这种多层栈和交叉验证绑在一起，避免上一层在同一批标签上既拟合又输出，导致下一层背答案。使用时仍要自己留出从未参与各层训练的数据，用来估计真实泛化，而不是只看栈内部的交叉验证分数。

数据很少时不要叠很多层。每层都会吃掉样本的有效信息，元模型的列数还随基模型个数变宽，小样本上很容易把噪声当成新特征。它适合已经有一批互相有差别的强模型、又希望系统地组织它们的场合，而不是用来代替第一份基线。

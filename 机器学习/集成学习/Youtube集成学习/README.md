# 比赛里把模型叠起来的顺序

一段公开课把融合讲成一条可执行的顺序，而不是一上来就叠十个模型。

先让一个简单模型跑通。用 5 折到 10 折的交叉验证估计分数，折数太少方差大，折数太多又慢。看的指标必须和榜单一致：回归常用绝对误差或均方根误差；分类可能是对数损失、ROC 面积，多标签时还会看到汉明损失。指标没对齐时，本地提升不一定换来名次。

这一版单模型就是基线。之后再换算法，每次只改一个因素，用同一套折去比，否则无法知道是模型变了还是划分变了。

不平衡时，准确率会把少数类淹没。训练可以用类别权重或只在训练折里做重采样；验证折保持原分布，用来计算真正的比赛指标。

超参数不要第一步就网格搜。网格把每个参数的候选做笛卡尔积，计算量和候选个数相乘，很贵。随机搜索在同样的预算下覆盖更多组合，适合先摸清哪些参数敏感。等敏感参数只剩两三个，再用小网格收紧。

提交时同时看本地交叉验证和公共榜。两者长期背离，多半是验证折和线上分布不一致，继续堆模型只会把错误拟合得更稳。

网格和随机搜索可以用同一预算对照。假设一个参数有 8 个候选，另一个有 8 个，网格要训练 64 次。若只允许训练 16 次，网格只能把每个参数收成 4 档，大量组合根本没被看到。随机抽 16 组时，每个参数的 8 个档位都有机会出现。等交叉验证指出只有学习率敏感，再对学习率做一维小网格即可。每次搜索都要写进同一张折的分数，不能换折之后宣称参数变好了。

回归看均方根时，误差大的样本会被平方放大；改成绝对误差后，最优参数可能换掉。分类的对数损失惩罚过分自信的错概率，ROC 面积只看排序。两个指标选出的模型可以不同，以比赛公告里的那个为准。

# 模型融合在压什么

把多个模型合在一起，为的是同时照顾两类误差：单个模型的系统偏差，以及换一批样本时预测乱跳的方差。不同做法压的侧重不一样。

袋装并行地训练很多棵树，预测时回归取平均、分类取多数。随机森林是这一路里最常用的，适合先做一版又快又稳的参照。

提升串行地加树。AdaBoost 提高分错样本的权重。梯度提升树让新树去拟合残差（更一般地说是损失的负梯度）。XGBoost、LightGBM 沿这条线做了正则、直方图和工程加速。CatBoost 另外强调类别列可以直接送进提升过程。

投票不训练第二层：硬投票比标签票数，软投票比各类概率的加权平均。

栈式融合（Stacking）用交叉验证收集每个基模型的预测，再训练一个元模型。基模型宜选强的，而且彼此的错误不要完全重合。

混合（Blending）同样把预测当新特征，但只用一份留出的验证集来生成元模型的训练行，不再做多折。样本很充足时，留出集够大，实现比多折栈式简单；样本少时，留出集一划分，元模型能看到的行就不够了。

无论哪一种，融合前先确认单个模型已经在同一套验证划分上可比较。一个明显失效的模型塞进来，投票和栈式都会被它拖偏。

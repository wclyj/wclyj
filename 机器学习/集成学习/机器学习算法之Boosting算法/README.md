# Boosting：把弱规则收成一个强预测

Boosting 是监督学习里的一类集成。监督的意思是每条训练样本既有输入也有希望得到的输出。输出是连续数时做回归，例如预测明日最高气温；输出是有限个类别时做分类，例如预测明日是晴、阴还是雨。无监督没有标签，典型任务是聚类、降维、或者估计哪些商品会一起出现。Boosting 本身不负责发现没有标签的结构，它要求已经有 `y`。

## 个体学习器怎样摆在一起

先各自训练，再用某种规则合并，这个模式也叫多分类器系统或委员会方法。只使用同一种算法时，叫同质集成，那些成员是基学习器，例如「全是树」。混用逻辑回归、树和核方法时，叫异质集成，成员更适合叫组件。Boosting 的经典形态是同质的：同一类弱学习器按顺序产生。袋装和随机森林也是同质，但成员之间没有「后一个必须等前一个的残差」这种强依赖，可以并行长出来。

同质并不等于成员真的一样。成员必须「好而不同」：每个都要比随机猜测强，而且不能在同一些样本上犯同样的错。只有准确、没有差别，合并等于没合并；只有差别、准确率却低于掷硬币，合并会更差。

用三行样本、三个分类器看投票（对号表示判对）：

| | 样本甲 | 样本乙 | 样本丙 | 准确率 |
| --- | --- | --- | --- | --- |
| 分类器 1 | 对 | 对 | 错 | 2/3 |
| 分类器 2 | 错 | 对 | 对 | 2/3 |
| 分类器 3 | 对 | 错 | 对 | 2/3 |
| 多数票 | 对 | 对 | 对 | 3/3 |

错误错开了，投票把三条都救回来。若三个分类器在甲乙丙上错得完全一样，投票仍是 2/3，没有收益。若每个分类器都只有 1/3 正确，而且错的方向一致，投票会稳定地选错。因此「成员错误率相互独立且都低于 1/2」时，成员变多，集成错误率会往下掉；真实任务里它们面对同一份数据，错误做不到独立。准确和多样是在抢同一份容量：模型强到都逼近贝叶斯误差时，剩下的差别往往变小。集成研究的核心就是如何制造还够用、又不完全重合的成员。

三种常见框架对应三种制造差别的办法。

- 袋装：每个成员看一份有放回的子样本，预测再平均或投票。差别来自样本扰动，以及随机森林里的特征扰动。
- 提升：成员按轮次产生。每一轮的训练分布或训练标签被改写，后一轮补前一轮。预测是各轮输出的加权和，不是无权重的票数。
- 栈式融合：成员先对训练集做出预测，把「第 `j` 个成员对第 `i` 行的预测」当成新矩阵的第 `i` 行第 `j` 列，再训练一个元模型。差别不仅要出现在成员之间，还要被元模型利用。

直觉上成员一多就不容易过拟合。这个直觉不可靠。袋装的平均主要降低方差，偏差基本留在原处。提升故意降低偏差，树一多、步长再大，方差会回来。下面用偏差和方差把这件事说死，再进入具体算法。

## 偏差、方差，和「弱」到底弱在哪

偏差是预测期望与真实规律之间的差距，表现成训练集上都拟合不好。方差是换一份同样规模的训练集时，模型跟着变多少。两份训练集长出的树结构差很远，通常说明方差大，拿到第三份数据就容易失灵，也就是过拟合的一种机制。

线性模型的系数差、树的切分差，都可以理解为模型之间的距离。讨论集成时往往不需要把这个距离算成一个数，只要能比较「更稳」还是「更飘」。常说的弱学习器，是偏差偏高、方差偏低的那种：一棵深度为 1 的树桩在训练集上并不准，但结构简单，抽样稍变也不会长成完全不同的样子。强学习器则相反，单棵很深的树训练准确率高，结构也脆。

Boosting 的赌注是：我可以只用弱成员，靠许多轮把偏差补上，并用小步长限制方差不要升太快。若成员本身已经极强，每一轮的残差大部分是噪声，继续加只会记噪声。

## 提升在改什么

弱规则可以来自任何能处理加权样本的算法。选择规则的过程是迭代的：

1. 开始时每条样本一样重。
2. 用当前权重训练一个弱规则。
3. 被它分错的样本在下一轮加重，分对的减轻。
4. 达到预定轮数或预定精度就停。
5. 按各轮的把握把弱规则加总。

最常被放在一起比较的三个名字是 AdaBoost、梯度提升机（GBM / GBDT）和 XGBoost。三者都是前向加成员，成员目标的定义不同。

## AdaBoost

求一个粗糙规则比求一个一步到位的精确规则容易。AdaBoost 反复调用弱算法，每轮面对的样本分布不同，最后做加权多数表决。

它要回答的两个设计问题是：

- 下一轮的分布怎么改：提高上一轮分错样本的权重，降低分对样本的权重。分错的点因此更可能决定下一棵树桩的切分。
- 表决时谁说了算：这一轮的加权错误率越低，它的系数越大；错误率接近 0.5，系数接近 0，几乎不参与表决。

可以用四格示意图想象，而不必依赖某一张图。第一格里正负样本权重相同，树桩切错了左上角三个正样本。第二格这三个正样本变重，新树桩迁就它们，却把右下角三个负样本切错。第三格改为重罚那三个负样本，再长一棵树桩。第四格把三棵树桩按系数相加，单独每一棵都有成片的错，相加后的符号在大多数格子上是对的。

回归时没有「类标签的票」，但「加大当前误差大的样本的权重、再拟合」这个动作还在。误差的定义换成残差的大小。

深度为 1 的树能接受样本权重，所以经常当基学习器。任何支持 `sample_weight` 的模型都可以替换进去，但太强的基学习器会让「弱规则」这个前提失效。轮数 `n_estimators` 和学习率一起决定总容量：学习率小，就要更多轮才能达到同样的训练损失。现代 scikit-learn 里基学习器参数名是 `estimator`（旧版本叫 `base_estimator`）。

```python
from sklearn.ensemble import AdaBoostClassifier
from sklearn.tree import DecisionTreeClassifier

stump = DecisionTreeClassifier(max_depth=1)
model = AdaBoostClassifier(
    estimator=stump,
    n_estimators=40,
    learning_rate=0.8,
)
model.fit(train_x, train_y)
```

这里的 40 和 0.8 只是一组保守起点。验证误差若还在降，再加轮数；训练误差很低而验证误差上升，先减小学习率或限制树桩以外的深度，而不是继续加轮。

## 梯度提升

梯度提升同样把弱成员加成强预测，但下一轮不再直接改样本权重，而是改成员要拟合的目标。损失用来度量「当前总和有多不靠谱」。若损失还能下降，模型就还没走完。下降最快的方向是负梯度。在提升里，走的这一小步不是一个标量，而是一棵函数：新的树。

把总和写成 `F_m = F_{m-1} + η h_m`。希望 `F_m` 更接近 `y`，也就是希望 `h_m` 接近「还没被解释的那一部分」。平方损失下，这一部分就是残差 `y - F_{m-1}`。对平方损失求导会看到：残差与负梯度只差一个常数倍，拟合残差就是沿着负梯度走。换成其他可微损失，就改在当前预测处计算负梯度，让回归树去拟合它。

因此和 AdaBoost 的对照可以记成两句：

- AdaBoost 放大分错样本的权重，成员多是很浅的树，合并系数由错误率导出。
- 梯度提升保持样本权重不变（除非另外再加权），用负梯度当回归目标，成员常是深度略大于 1 的回归树，合并系数里有一个单独的学习率。

代表实现是 GBDT。它能包住多种可微损失，分类和回归都做。下面一组起点用很浅的树和偏大的学习率，便于在小数据上看到过拟合，而不是推荐的最终参数：

```python
from sklearn.ensemble import GradientBoostingClassifier

gbdt = GradientBoostingClassifier(
    n_estimators=80,
    learning_rate=0.1,
    max_depth=2,
)
gbdt.fit(train_x, train_y)
```

`max_depth` 限制单棵树的结点预算。深度 2 的树已经能做简单交互，深度再大，单棵的方差上去，提升「用很多弱树」的好处变少。损失函数可以按任务换：回归里的平方、绝对误差，分类里的对数损失，换的是负梯度的公式，加树的骨架不变。

## XGBoost 相对 GBDT 改了什么

XGBoost 是梯度提升的一种高效实现，基学习器可以是树（`gbtree`），也可以是线性函数（`gblinear`）。线性模式下它接近带正则的线性回归或逻辑回归，不再长树。默认讨论的仍是树。

GBDT 这个名字本身包含三块：用树做成员、按轮加上去、方向由梯度决定。XGBoost 沿用这三块，再改损失的近似、复杂度和找切点的算法。

常规的一轮仍是：有一个当前预测；计算梯度（以及下面要说的二阶导）；长一棵树去拟合它；求出叶子上的分数；用学习率缩减后加回预测。

相对教科书式的 GBDT，差别集中在这些地方。

1. 泰勒展开留到二阶。只靠一阶导时，步长要靠线搜索或固定学习率去猜。写出二阶导 `h` 之后，叶子分数有闭式解，近似也更贴损失曲面。自定义损失只要能给出一阶和二阶导就能接进去。
2. 目标里多了叶子个数和叶子分数的 L2 罚项。从偏差-方差看，罚项压的是方差，树更不愿意为了几个样本新开叶子。
3. 收缩。每棵树的叶子分数乘上 `η`（接口里常叫 `eta` 或 `learning_rate`）再累加。`η` 小、轮数多，比「`η` 大、轮数少」更稳。传统 GBDT 同样可以乘学习率，这不是唯一的差别，但在 XGBoost 里它和正则一起用。
4. 列采样。长树前或每个结点上随机抽特征，随机森林用过的这一招被拿来降低过拟合，并减少要评估的列。
5. 缺失值有默认分支。不必事先填均值。算法比较「缺值进左」和「缺值进右」哪个增益大，把方向记在结点上。
6. 并行发生在特征上，不是发生在「第 `t` 棵树和第 `t+1` 棵树」之间。第 `t` 轮的目标含有前 `t-1` 轮的预测，轮次仍然串行。耗时的是为每个特征找最佳切点，不同特征的增益可以分线程，再取增益最大的那个特征来分。
7. 训练前把特征排序结果放进块结构，后面的树重复使用，避免每轮重排。块也让上述按列并行更自然。
8. 精确枚举切点在数据超出内存时太慢，于是有分位数近似：先挑候选切点，再只在候选上算增益。近似算法也可以并行着建那些候选。

叶子分数的罚项同时看叶子数量和分数的大小，所以「再分一次」必须让一阶、二阶统计量证明这次分裂值回票价。这就是增益公式里要减去 `γ` 的原因。增益不够就停，这比事先写死深度更贴着损失走，但深度限制仍然有用，作为第二道闸门。

和随机森林比，XGBoost 的树是有顺序的，前一棵的预测会进入后一棵的梯度。把 `n_estimators` 设得很大而 `eta` 不减小，后段的树仍会拟合梯度噪声。早停应盯着验证集。

## 使用前的最低要求

成员要够好：二分类里加权错误率长期高于一半，就不要再加了。成员要有差别：若每一轮的树在验证集上预测几乎相同，多半是学习率太小而深度又不够，或者特征本身分不开标签。满足这两条之前，换更复杂的融合（再叠一层元模型）没有意义。

调参时先固定一套交叉验证，再动三个旋钮：学习率、轮数、树的容量（深度或叶子数）。三个一起网格搜索，无法判断是哪一个在起作用。类别极不平衡时，先处理训练权重或只在训练折内做重采样，再谈提升；否则梯度会被多数类占满，少数类在负梯度里没有声音。

## 把一轮 AdaBoost 的系数算完

六条样本，标签 `+ + + - - -`，初始权重各 `1/6`。第一棵树桩错了两条正样本，加权错误率 `ε = 2/6 ≈ 0.333`。系数

`α = 0.5 * ln((1-0.333)/0.333) = 0.5 * ln(2) ≈ 0.347`

分对的 4 条，未归一化权重变为 `(1/6) * exp(-0.347) ≈ 0.118`；分错的 2 条变为 `(1/6) * exp(0.347) ≈ 0.236`。总和 `4*0.118 + 2*0.236 = 0.944`。归一化后，每条分对样本约 0.125，每条分错样本约 0.250。错的样本权重合计仍是 0.5，但它们只有两条，所以下一条树桩会优先把这两条切开。若第二轮错误率升到 0.45，`α` 只剩大约 0.100，这轮在最终符号里几乎说不上话。错误率到 0.5 时对数里的比值是 1，系数为 0，这一轮可以直接丢弃。

这个计算也说明学习率的位置：若把 `α` 再乘 0.5，权重更新没那么猛，需要更多轮才能把难样本的权重抬上去。轮数不够时，小学习率看起来「没学到」，其实是步子还没走完。

## 平方损失下的两轮残差

四个点的目标是 1、3、5、7，初始预测全取平均 4。残差为 -3、-1、+1、+3。第一棵树把前两个点分到左叶、后两个点分到右叶，叶子值取残差平均，即 -2 和 +2。学习率 1 时预测变成 2、2、6、6，新残差 -1、+1、-1、+1。

第二棵树若只能按同一特征再切，左右仍然各含一个 -1 和一个 +1，叶子值变成 0，残差不再下降。这说明提升不是魔法：特征若分不开剩下的结构，新树的叶子值会接近 0，加多少轮都一样。换一个能把第 1 和第 3 个点分到一起的特征，叶子才能拟合 `-1,+1` 这种交错。检查一棵新树是否有用，看验证集损失，而不是看它在训练集残差上是否为零。训练残差为零只说明叶子记住了这四个点。

## 偏差下降、方差回升的一个对照

同一份数据用深度 1 的树桩做提升，前几轮验证误差通常明显下降，因为每轮都在补系统性的分错。轮数继续增加后，训练误差还能降，验证误差开始抬头，后加的树桩在追逐权重大的个别点。把深度改成 8 再提升，第一轮的训练误差就已经很低，验证误差往往从第二轮起变差。深度把单棵的方差先拉高了，提升没有弱成员可以叠。实践里先把单棵限制在浅层，用验证曲线决定停在哪一轮，比一开始就用深树更符合这套方法的假设。

列采样和子样本会让相邻两轮的树少看一些相同的列或相同的行，错误没那么重合，验证曲线的抬头会晚一些。它们不改变「前向加树」的骨架，只是在制造成员之间的差别。差别若已经足够，再把比例降得很低，单棵树看到的信息太少，偏差又会补不回来。

## 三个名字不要混用的并行

AdaBoost 的下一轮权重依赖上一轮谁分错了，轮与轮必须有先后。梯度提升的下一棵树依赖当前总和的梯度，同样有先后。说 XGBoost「能并行」时，指的是同一轮里不同列的切点可以分线程去找，排好序的块可以被多个线程读。它不会同时长出第 5 棵和第 6 棵还保证结果与串行相同。随机森林才是树与树并行：每棵树的样本和特征子集都独立。

把两者放在同一张验证表上比较时，森林的分数通常更稳、上限有时较低；提升的上限更高，但对学习率和轮数敏感。若提升的验证曲线已经抬头，再增加树只会加大方差，这时换回森林或减小步长，比再换一个更复杂的损失更直接。损失本身要和指标一致：排序指标下，把概率校准得很好并不会自动提高名次；对数损失下，只保证排序、不保证概率刻度，则会吃亏。先选定损失，再谈树有多深。

四个点的目标 1、3、5、7 上，平均预测 4 的平方误差是 `(9+1+1+9)/4 = 5`。加上第一棵残差树之后预测为 2、2、6、6，平方误差变成 `(1+1+1+1)/4 = 1`。这是训练误差。若这四个点的验证同伴其实满足另一套关系，这一步的验证误差可能上升。只报告训练误差从 5 降到 1，不能当作模型变好的证据。

再看成员个数和错误率的关系时，不要把「理论上独立」写成「训练出来就会独立」。三棵树若共用同一批特征、同一批难样本，它们的错会扎堆。投票表里那种完美互补，要靠样本扰动、特征扰动或不同的损失去逼近，不会自动出现。检查互补的简便办法是看两两预测的不一致比例：低到接近 0，增加成员没有意义；高到随便猜，说明有的成员已经不可用。介于两者之间，才值得继续加轮或加树。学习率、深度、列采样都是在调这个不一致比例，同时守住单棵还比随机好。这三个旋钮分开动，每次只留一个变化，验证曲线才读得懂。曲线只在训练集上下降、验证集不动，说明加进去的是噪声，应停在验证最优的那一轮，而不是停在训练误差的最低处。

# 这一组笔记在讲什么

这里把「从一棵树到一堆树」拆成两段，方便分开看。

第一段只谈单棵树。分类时用信息熵或基尼不纯度决定往哪切；回归时叶子里放的是数值，切分要让叶子内部的波动变小。先把「一次分裂在优化什么」算清楚，后面每棵提升树在拟合什么才不会变成口号。

第二段谈怎么把多棵树放在一起。袋装（Bagging）让树互相独立、结果再平均或投票，随机森林是它最常用的样子。提升（Boosting）则是一棵接一棵，后一棵补前一棵的不足：AdaBoost 改样本权重，梯度提升树改的是损失的梯度，XGBoost 把二阶导数和复杂度罚项写进同一目标，LightGBM 换了直方图、按叶子生长，并加上采样和特征捆绑来省时间。

竞赛里还会把已经训练好的模型再叠一层（Stacking、Blending）。那是模型输出的再次学习，和「以树为基学习器的提升」不是同一条流水线。读的时候先分清：你现在调的是树的分裂，是样本权重，还是第二层的输入列。

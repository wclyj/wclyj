# 云原生入门课在讲什么

这是一条从容器到 Kubernetes，再到 KubeSphere 的实操大纲，面向第一次把服务放到集群上的人。它不展开控制面源码，也不替代进阶课程里的调度器和网络专题。

## 适合谁

- 写业务、想自己把服务跑到集群上的开发
- 从物理机或虚拟机脚本转到声明式发布的运维
- 需要在测试环境复现发布过程的测试
- 要为团队选技术路线的架构角色

默认你会基本的 Linux、用过 Nginx、MySQL 或 Redis。若接触过 Spring Cloud 一类的多服务调用，后面的微服务章节会更容易对照。

## 课怎么上

概念和操作穿插：每引入一个对象，就在同一套云上环境把它创建出来。不在每人笔记本上拼本地虚拟机，减少“我的网卡配置和讲师不同”这类差异。答疑和配套材料走课程自己的主页，笔记只保留操作要点。

## 大纲

1. 课程说明。说明读者是初学者，高级特性另寻专题。先分清公有云和私有云，以及云服务器、VPC 在集群里各干什么。
2. 容器基础。安装 Docker，拉取和运行镜像，映射端口，用卷把数据留在容器外面。
3. Kubernetes 基础。说明它解决的编排问题；用 kubeadm 拉起集群；依次练习 Pod、Namespace、Deployment、Service、Ingress。StatefulSet 只建立“有身份、有存储”的印象，不在这里展开运维细节。
4. 用 KubeSphere 降低集群的安装和操作成本。包括单机 All-in-One、多节点、叠加到已有 Kubernetes、界面日常操作、控制面高可用、离线包、从旧版升到 3.1 一线，以及多集群。
5. 在 KubeSphere 里管集群和应用，把前面零散的 kubectl 操作收成项目、命名空间和应用模板。
6. DevOps。概念、一条从提交到部署的过程、发布后的弹性、示例应用沙盘、企业里谁来推动、常见工具如何衔接、流水线如何设计，以及在 KubeSphere 上把流水线跑起来。
7. 微服务。概念和落地顺序：先在平台上放一个最小服务，再对照 Spring Cloud 和 Dubbo 的示例，最后讨论已有系统怎样拆。
8. 可观测性。日志的使用场景、KubeSphere 收集日志的路径、把应用日志接进去；监控部分从 Prometheus 的角色讲到平台上的告警实操。
9. 边缘。讨论应用从中心集群延伸到边缘节点时，平台能提供的管理方式。

建议顺序不要跳：没有容器和 Service 的概念时，直接进 KubeSphere 的项目空间，会分不清界面上的按钮对应哪一种对象。

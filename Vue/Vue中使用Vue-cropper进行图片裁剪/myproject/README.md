# myproject

> 基于 webpack 模板的 Vue 工程，页面里演示矩形裁剪。

## Build Setup

```bash
# 安装依赖
npm install

# 开发服务，热更新地址 localhost:8080
npm run dev

# 生产构建
npm run build

# 生产构建并打开体积分析
npm run build --report
```

目录分工见 [webpack 模板说明](http://vuejs-templates.github.io/webpack/)，单文件组件编译见 [vue-loader 文档](http://vuejs.github.io/vue-loader)。

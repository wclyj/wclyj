# Vue内容页面SEO优化方案

课程详情既是预览页，也是被搜索引擎收录的落地页。技术方案要先定详情页，再谈预览。单页应用首屏 HTML 几乎是空的，对收录不友好。

## 技术需求

详情页展示课程卖点，访问量会集中在少数热门课上。内容要完整，打开也要快。有统计认为超过数秒仍打不开，访客就会离开。另一项要求是让爬虫能直接读到正文并生成快照，而不是只看到一个挂载点。

## 解决方案

在还能被收录的前提下把响应时间压下去，可以走两条路。

### 方案1：

读多写少的详情适合用缓存挡住数据库。同一门课在缓存命中时不再查表，未命中才回源并回填。

这条路仍由 Servlet 或 JSP 在应用服务器上拼 HTML，属于动态渲染。和完全不缓存相比，数据库压力会下来。

- 优点：热点课程走缓存，响应更稳。
- 缺点：HTML 仍在应用服务器上生成，并发上来时机器本身会先成为瓶颈。

### 方案2

不常改的详情可以提前渲染成静态 HTML，放到 Nginx 上，访客和爬虫都直接拿文件。价格、库存这类会变的片段再用接口补，页面主体不跟着接口走。

静态文件的并发能力远高于应用服务器拼页面。更新课程时要主动刷新对应 HTML，否则收录的仍是旧文案。纯单页把全部数据留在接口里，不适合作为这张详情页的最终形态。

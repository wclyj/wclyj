# 希尔排序

## 题目描述

把整数数组按升序排好。希尔排序是插入排序的间隔版：先让距离较远的元素变成大致有序，再逐步把间隔缩小到 1，最后一轮就是普通插入排序。

## 思路

插入排序每次只和相邻位置比较，一个很小的数若落在末尾，要一步步挪过整个数组。希尔排序先选一个间隔 `h`，把下标相差 `h` 的元素各自做插入排序。这样一次交换可以跨过 `h` 个位置。

间隔用 `h = 3h + 1` 往上长，只要它还小于长度的三分之一就继续。排序时再不断整除 3，直到间隔变成 1。最后一轮间隔为 1，保证结果整体有序。

## 演算示例

数组 `[9, 3, 7, 1, 8, 4, 2]`，长度 7。`7 / 3` 约是 2.33，`h` 从 1 变成 `3×1+1 = 4` 后就不再增大。

间隔 4 时，分组是下标 `(0,4)`、`(1,5)`、`(2,6)`，下标 3 单独一组：

- 9 和 8：8 更小，交换成 `[8, 3, 7, 1, 9, 4, 2]`
- 3 和 4：已经有序
- 7 和 2：交换成 `[8, 3, 2, 1, 9, 4, 7]`

间隔缩到 1，对 `[8, 3, 2, 1, 9, 4, 7]` 做一次插入排序，得到 `[1, 2, 3, 4, 7, 8, 9]`。

## 代码

```python
class Solution:
    def shell_sort(self, array):
        data = list(array)
        size = len(data)
        gap = 1
        while gap < size / 3:
            gap = gap * 3 + 1
        while gap >= 1:
            for i in range(gap, size):
                current = data[i]
                j = i
                while j >= gap and data[j - gap] > current:
                    data[j] = data[j - gap]
                    j -= gap
                data[j] = current
            gap //= 3
        return data


if __name__ == "__main__":
    solver = Solution()
    assert solver.shell_sort([9, 3, 7, 1, 8, 4, 2]) == [1, 2, 3, 4, 7, 8, 9]
    assert solver.shell_sort([]) == []
    assert solver.shell_sort([5]) == [5]
    assert solver.shell_sort([1, 2, 3]) == [1, 2, 3]
    assert solver.shell_sort([4, 4, 1]) == [1, 4, 4]
    print(solver.shell_sort([9, 3, 7, 1, 8, 4, 2]))
```

## 复杂度

间隔序列决定复杂度。上面这种 `3h+1` 的间隔，常见的上界大约是 `O(n^1.5)` 量级，最坏情况仍可能到 `O(n^2)`。额外空间 `O(1)`。它不是稳定排序，远距离交换可能打乱相等元素原来的顺序。

## 反例与边界

- 间隔如果从大于长度的值开始，并且循环条件写成「大于长度才增大」，间隔会停在 1，算法退化为插入排序。结果仍然正确，但失去了预先跨距离交换的意义。
- 若最后一轮不把间隔降到 1 就停止，各组内部有序并不能推出整个数组有序。例如只按间隔 4 排完，`[8, 3, 2, 1, 9, 4, 7]` 还不是升序。
- 空数组和单元素不用进入交换，直接返回。

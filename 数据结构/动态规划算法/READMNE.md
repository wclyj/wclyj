# 动态规划问题

文件名沿用原来的拼写。这一篇用填表把 0-1 背包从头推一遍。

## 应用场景

包的承重是 5 斤。三件物品每件最多拿一次：

| 物品 | 重量 | 价值 |
| ---- | ---- | ---- |
| 笔袋 | 1    | 6    |
| 本子 | 3    | 8    |
| 台灯 | 4    | 11   |

目标：总重不超过 5，总价值最大。不能把同一件放两次。

## 动态规划算法

### 概念

大问题拆成「只允许前几件物品、承重只到某个整数」的小问题。这些小问题会共用更小的结果，所以不像分治那样各算各的，而是把答案记进一张表，从表的左上角推到右下角。

### 求解 0-1背包问题

给定容量、每件物品的重量和价值，选若干件使价值最大。0-1 的意思是每件只有「放」或「不放」。若每件可以拿无限次，那是完全背包，转移时要改成引用同一行已经更新过的格子，不能照搬这里的上一行。

### 主要思想

`best[i][c]`：只考虑前 `i` 件物品、承重不超过 `c` 时的最大价值。重量数组 `w`、价值数组 `val` 都从 0 编号，表从 1 编号，所以第 `i` 件对应 `w[i-1]`、`val[i-1]`。

- `best[i][0] = best[0][c] = 0`：没有容量或没有物品，价值是 0。
- 若 `w[i-1] > c`：这件放不进，`best[i][c] = best[i-1][c]`。
- 若 `c >= w[i-1]`：`best[i][c] = max(best[i-1][c], val[i-1] + best[i-1][c - w[i-1]])`。

### 思路推导图

容量按 1 斤一格，从 0 列到 5 列。先只允许笔袋，再加入本子，最后加入台灯。

| 已考虑的物品 | 0斤 | 1斤 | 2斤 | 3斤 | 4斤 | 5斤 |
| ------------ | --- | --- | --- | --- | --- | --- |
| 空           | 0   | 0   | 0   | 0   | 0   | 0   |
| 笔袋 1/6     | 0   | 6   | 6   | 6   | 6   | 6   |
| 再加本子 3/8 | 0   | 6   | 6   | 8   | 14  | 14  |
| 再加台灯 4/11 | 0  | 6   | 6   | 8   | 14  | 17  |

口头对一下两个格子，避免公式只停留在符号上。

验证 1：只放笔袋、容量 1。`i = 1, c = 1, w = 1`，放得下。`max(best[0][1], 6 + best[0][0]) = max(0, 6) = 6`。

验证 2：三件都考虑、容量 5。台灯重 4，放得下。不放台灯则沿用上一行的 14（笔袋+本子）；放台灯则 `11 + best[2][1] = 11 + 6 = 17`。取 17。17 对应笔袋和台灯，总重 5。本子和台灯总重 7，超出，表里不会出现。

另一格：容量 4、加入台灯时，`max(14, 11 + best[2][0]) = max(14, 11) = 14`。单放台灯只有 11，不如笔袋加本子。

## 代码实现

```python
def pack_items(weights, values, limit):
    """返回 (最大价值, 选中的物品下标列表)。下标从 0 计。"""
    kinds = len(values)
    best = [[0] * (limit + 1) for _ in range(kinds + 1)]
    take = [[False] * (limit + 1) for _ in range(kinds + 1)]
    for i in range(1, kinds + 1):
        wt = weights[i - 1]
        gain = values[i - 1]
        for cap in range(1, limit + 1):
            best[i][cap] = best[i - 1][cap]
            if wt <= cap:
                with_it = gain + best[i - 1][cap - wt]
                if with_it > best[i][cap]:
                    best[i][cap] = with_it
                    take[i][cap] = True
    chosen = []
    row, col = kinds, limit
    while row > 0 and col > 0:
        if take[row][col]:
            chosen.append(row - 1)
            col -= weights[row - 1]
        row -= 1
    chosen.reverse()
    return best[kinds][limit], chosen
```

对笔袋、本子、台灯跑一遍，表的最后一行是 `0 6 6 8 14 17`，选中下标 `[0, 2]`，价值 17。

### 复杂度

时间 `O(种类 × 容量)`，空间同样量级。容量很大而物品很少时，这张表会比直接枚举子集更费；物品一多，`2^n` 的枚举就不如填表。

### 边界

- 容量是 0，或一件都没有：价值 0，清单为空。
- 某件比容量还重，例如容量 5 时再来一件重 9 的物品：整行复制上一行，不能出现负数下标。
- 价值相同的两种放法，上面的代码在「严格大于」时才改口，所以保留先出现的那种。若题目要求字典序最小的方案，比较条件要另写。

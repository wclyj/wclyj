# 动态规划

同一问若被拆出来很多次，就把子问题的答案存下来，每个只算一次。先用自顶向下把递推关系想清楚，再自底向上填表，避免递归重复进入同一个状态。

## 斐波那契数列

记 `F(0) = 0`，`F(1) = 1`，其后每一项是前两项之和。求 `F(7)`。手算：0, 1, 1, 2, 3, 5, 8, 13，所以 `F(7) = 13`。规定 `n <= 39`，避免递归演示时栈太深。

直接递归会把 `F(5)` 在求 `F(7)` 和求 `F(6)` 时各算一遍，`F(4)` 次数更多，调用次数按指数涨。

### 保留中间结果

用字典记住已经算出的项。求 `F(7)` 时实际新算的只有 2 到 7 这几项，每项只写一次。这种「先假设更小的项会回来，再把结果塞进字典」也叫记忆化搜索，方向是自顶向下。

```python
def fib_cached(n, memo=None):
    if memo is None:
        memo = {0: 0, 1: 1}
    if n not in memo:
        memo[n] = fib_cached(n - 1, memo) + fib_cached(n - 2, memo)
    return memo[n]
```

### 动态规划

反过来，从 0 和 1 出发，顺着推出 7。这是自底向上。

| 下标 | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
| 值   | 0 | 1 | 1 | 2 | 3 | 5 | 8 | 13 |

```python
def fib_table(n):
    if n < 2:
        return n
    prev, cur = 0, 1
    for _ in range(2, n + 1):
        prev, cur = cur, prev + cur
    return cur
```

### 复杂度

记忆化和填表都是时间 `O(n)`、空间 `O(n)`；滚动两个变量后空间 `O(1)`。朴素递归时间 `O(φ^n)`。

### 边界

`n = 0` 必须返回 0。若基线只写了 `n == 1`，递归会向负数走。`n < 0` 在这题里没有定义，直接拒绝。

## 爬楼梯

### 来源

LeetCode 70。

### 描述

楼梯有 `n` 级，每次走 1 级或 2 级，问方案数。`n` 为正整数。

`n = 5` 时有 8 种：五个 1；三个组合是「一个 2 + 三个 1」的不同顺序（4 种）；两个 2 加一个 1 的不同顺序（3 种）。合计 8。不要用「2 级只有两种、3 级只有三种」这组当唯一例子，那只是递推的起点。

### 思考

到达第 `i` 级，最后一步要么从 `i-1` 走 1 级，要么从 `i-2` 走 2 级，方案数相加。和斐波那契同一形状，但起点不同：1 级是 1 种，2 级是 2 种。

### 走一遍

`dp[1] = 1`，`dp[2] = 2`。

- 3：1+2 = 3
- 4：2+3 = 5
- 5：3+5 = 8

### 代码

```python
def climb(n):
    if n <= 2:
        return n
    one, two = 1, 2
    for _ in range(3, n + 1):
        one, two = two, one + two
    return two
```

### 复杂度

时间 `O(n)`，空间 `O(1)`。

### 边界

`n = 1` 时循环不执行，直接返回 1。若把 `dp[2]` 写成 1（和斐波那契第 2 项搞混），`n = 2` 会少一种「一次走两级」。

## 三角形最小路径和

### 来源

LeetCode 120。

### 描述

三角形每个位置只能走到下一行里「同一列」或「右边一列」。求自顶向下的最小和。

```text
    [1]
   [2, 3]
  [1, 4, 2]
```

最小是 `1 → 2 → 1 = 4`。`1 → 3 → 2 = 6` 更大。

### 思路

从底往上改表。每个格子加上「下一行相邻两格里更小的那个」。改完后顶点就是答案。自顶向下也行，但要额外处理越界；从底往上时，最后一行本身就是已知的。

### 走一遍

底行 `[1, 4, 2]` 不动。中间行：`2 + min(1, 4) = 3`，`3 + min(4, 2) = 5`。顶点：`1 + min(3, 5) = 4`。

### 代码

```python
def triangle_min(rows):
    for r in range(len(rows) - 2, -1, -1):
        for c in range(len(rows[r])):
            rows[r][c] += min(rows[r + 1][c], rows[r + 1][c + 1])
    return rows[0][0]
```

### 复杂度

时间、空间都与格子数成正比。上面原地改写，额外空间 `O(1)`。调用方若还要原三角形，先拷贝一份。

### 边界

只有 `[8]` 一行：循环不跑，答案就是 8。负数格子也成立，因为转移只取相邻最小值，不依赖「越加越大」。

## 最小路径和

### 来源

LeetCode 64。原文只有题面，这里补上转移和代码。

### 描述

`m` 行 `n` 列非负格子，从左上到右下，每次只能向右或向下，路径上的数字之和要最小。

```text
2  1  4
3  8  1
```

一条路是 `2 → 1 → 4 → 1`，和为 8。`2 → 3 → 8 → 1` 是 14。答案 8。

### 思路

`dp[r][c]` 表示走到 `(r, c)` 的最小和。第一行只能从左边来，第一列只能从上面来，其余取上、左较小者再加自己。

### 走一遍

第一行累加成 `2, 3, 7`。第一列累加成 `2, 5`。右下角：`1 + min(7 从左, 5+8=13 从上)`，先把中间算完：`(1,1)` 是 `8 + min(3, 5) = 11`，右下是 `1 + min(11, 7) = 8`。

### 代码

```python
def min_path_sum(grid):
    rows, cols = len(grid), len(grid[0])
    for c in range(1, cols):
        grid[0][c] += grid[0][c - 1]
    for r in range(1, rows):
        grid[r][0] += grid[r - 1][0]
        for c in range(1, cols):
            grid[r][c] += min(grid[r - 1][c], grid[r][c - 1])
    return grid[-1][-1]
```

### 复杂度

时间 `O(mn)`，原地写则额外空间 `O(1)`。

### 边界

单格 `[[6]]` 没有路可走，答案是 6。空表不是合法输入。格子若出现负数，这条递推仍然对，只是题面限定了非负。

## 整数拆分

### 来源

LeetCode 343。

### 描述

正整数 `n`（至少 2，至多 58）拆成至少两个正整数之和，让这些整数的乘积最大。

`n = 8`。`3+3+2` 的乘积是 18；`2+2+2+2` 是 16；`4+4` 是 16。答案 18。`n = 2` 只能 `1+1`，乘积 1。

### 思路

暴力是把拆分画成一棵递归树，同一个余数会被反复拆。最优子结构：`n` 的最优乘积，来自「切下一刀 `j`，右边要么不再拆（`j * (n-j)`），要么继续用右边的最优拆分（`j * dp[n-j]`）」。

### 最优子结构

`dp[i] = max(j * (i-j), j * dp[i-j])`，`j` 从 1 到 `i-1`。`dp[1]` 没有「至少拆成两段」的合法乘积，当作继续拆分时的底，记 1 即可（真正的答案从 2 开始）。

### 方法1

自顶向下，字典去重。

```python
def break_memo(n, memo=None):
    if n <= 2:
        return 1
    if memo is None:
        memo = {}
    if n in memo:
        return memo[n]
    best = 0
    for left in range(1, n):
        right = n - left
        best = max(best, left * right, left * break_memo(right, memo))
    memo[n] = best
    return best
```

### 方法2

自底向上。`i` 从 2 推到 `n`，内层枚举第一刀。

```python
def break_dp(n):
    best = [0] * (n + 1)
    best[1] = 1
    for i in range(2, n + 1):
        for left in range(1, i):
            right = i - left
            best[i] = max(best[i], left * right, left * best[right])
    return best[n]
```

### 走一遍

`dp[2] = 1`，`dp[3] = 2`，`dp[4] = 4`，`dp[5] = 6`，`dp[6] = 9`，`dp[7] = 12`，`dp[8] = 18`（来自 `3 * dp[5] = 3 * 6`）。

### 复杂度

两重循环 `O(n^2)`，空间 `O(n)`。记忆化状态也是 `O(n)` 个，每个状态里还有一层循环，同样 `O(n^2)`。

### 边界

`n = 2` 不能返回 `dp[1] * 1` 这种没切开的值。循环只比较 `left * right`，得到 1。`n = 3` 是 2，比「不拆」的 3 小，但题目要求至少切一刀，所以答案是 2，不是 3。

## 完全平方数

### 来源

LeetCode 279。原文只有题面。

### 描述

正整数 `n` 写成若干完全平方数之和，平方数可以重复，个数要最少。

`n = 7`。`4+1+1+1` 用了 4 个。两个平方数凑不出 7，三个也凑不出（`4+1+1` 已经是三个里最小的组合，和是 6，再换更大的平方就超过）。答案是 4。

### 思路

`dp[x]` 是凑出 `x` 的最少个数。枚举最后一块平方 `k*k`，`dp[x] = min(dp[x - k*k] + 1)`。

### 走一遍

`dp[0] = 0`，`dp[1] = 1`，`dp[2] = 2`，`dp[3] = 3`，`dp[4] = 1`，`dp[5] = 2`，`dp[6] = 3`，`dp[7] = min(dp[6]+1, dp[3]+1) = 4`。

### 代码

```python
def least_squares(n):
    need = [0] * (n + 1)
    for x in range(1, n + 1):
        need[x] = x
        k = 1
        while k * k <= x:
            need[x] = min(need[x], need[x - k * k] + 1)
            k += 1
    return need[n]
```

### 复杂度

时间 `O(n√n)`，空间 `O(n)`。

### 边界

`n = 1` 答案是 1，不是 0。`n = 0` 若被问到，一块都不用，是 0；题面一般从正整数开始。

## 解码方法

### 来源

LeetCode 91。原文只有题面。

### 描述

`'A'` 到 `'Z'` 对应 `1` 到 `26`。给一串数字，问有多少种译法。

`"231"`：可以是 `2|3|1`，也可以是 `23|1`。`31` 超过 26，不能当作一个字母。共 2 种。`"06"` 以 0 开头，0 不能单独译，也没有字母 `06`，答案 0。

### 思路

`dp[i]` 是前 `i` 个字符的译法数（`i` 为长度）。

- 第 `i` 个字符不是 `'0'`：可以单独译，加上 `dp[i-1]`。
- 它和前一个字符组成的两位数在 10 到 26：可以合译，加上 `dp[i-2]`。

### 走一遍

`"231"`。空串 1 种，第一个 `'2'` 合法，1 种。

- 看到 `'3'`：单译，1 种；`23` 合译，再加空串那 1 种，共 2。
- 看到 `'1'`：单译继承 2 种；`31` 非法，不加。答案 2。

### 代码

```python
def decode_ways(digits):
    if not digits or digits[0] == "0":
        return 0
    prev2, prev1 = 1, 1
    for i in range(1, len(digits)):
        cur = 0
        if digits[i] != "0":
            cur += prev1
        pair = int(digits[i - 1:i + 1])
        if 10 <= pair <= 26:
            cur += prev2
        prev2, prev1 = prev1, cur
    return prev1
```

### 复杂度

时间 `O(n)`，空间 `O(1)`。

### 边界

`"10"`：第二个字符是 0，不能单译；`10` 合法，答案 1。`"30"`：`30` 不在 1 到 26，单译又失败，答案 0。中间的 0 若写成「只要当前不是 0 就继承」，会把 `"30"` 错算成 1。

## 不同路径

### 来源

LeetCode 62，以及带障碍的 LeetCode 63。两题分开写。

### 描述

机器人在网格左上角，每次只能向右或向下，要到右下角。问路线条数。

高 3、宽 4 时，必须向下 2 步、向右 3 步，顺序任意，条数是 `C(5, 2) = 10`。

### 思路

`dp[r][c] = dp[r-1][c] + dp[r][c-1]`。第一行、第一列都只有一条直路，初始为 1。

### 走一遍

3 行 4 列的表：

```text
1  1  1  1
1  2  3  4
1  3  6  10
```

右下角 10。

### 代码

```python
def unique_paths(rows, cols):
    dp = [1] * cols
    for _ in range(1, rows):
        for c in range(1, cols):
            dp[c] += dp[c - 1]
    return dp[-1]
```

### 复杂度

时间 `O(行·列)`，滚动数组空间 `O(列)`。

### 边界

`1` 行或 `1` 列：只有一条直路。行列若从 0 开始不合法。

## 不同路径 II

### 描述

格子里 `1` 是障碍，不能踩，也不能从它穿过。`0` 可以走。

```text
0  1
0  0
```

向右第一步就被挡住，只能先向下再向右，1 条路。若左上角本身是 `1`，一步都迈不出，答案 0。

### 思路

障碍格的方案数是 0。第一行遇到障碍后，右边全部变成 0；第一列同理。其余格子仍是上加左，但障碍格保持 0。

### 代码

```python
def unique_paths_blocked(grid):
    if not grid or grid[0][0] == 1:
        return 0
    rows, cols = len(grid), len(grid[0])
    dp = [0] * cols
    dp[0] = 1
    for r in range(rows):
        for c in range(cols):
            if grid[r][c] == 1:
                dp[c] = 0
            elif c > 0:
                dp[c] += dp[c - 1]
    return dp[-1]
```

### 复杂度

时间 `O(行·列)`，空间 `O(列)`。

### 边界

右下角是障碍：最后一格被写成 0。只有一行且中间有障碍：障碍右侧应全是 0，不能再沿用「第一行全是 1」。

## 打家劫舍

### 来源

LeetCode 198。

### 描述

一条街的房屋金额存在数组里。相邻两间不能在同一夜偷，求最大金额。

`[4, 1, 2, 9]`。偷第 1 间和第 4 间得 `4+9 = 13`。偷第 1、第 3 间只有 6。答案 13。

### 思考

从下标 `i` 看到末尾，记作 `f(i)`。最优要么跳过 `i` 用 `f(i+1)`，要么拿走 `nums[i]` 再跳到 `f(i+2)`。展开来写就是在 `i, i+1, ...` 里选一个起点再跳两格，那个长式子和这条短递推是一回事，短的更适合填表。

### 记忆化搜索解决

```python
def rob_memo(nums):
    memo = {}

    def from_index(i):
        if i >= len(nums):
            return 0
        if i not in memo:
            skip = from_index(i + 1)
            take = nums[i] + from_index(i + 2)
            memo[i] = max(skip, take)
        return memo[i]

    return from_index(0)
```

### 动态规划解决

自底向上，`f(n) = 0`，`f(n-1) = nums[n-1]`，再往左填。

`[4, 1, 2, 9]`：

- 从下标 3：9
- 从下标 2：`max(2+0, 9) = 9`
- 从下标 1：`max(1+9, 9) = 10`
- 从下标 0：`max(4+9, 10) = 13`

```python
def rob_linear(nums):
    take_prev, skip_prev = 0, 0
    for money in nums:
        take_prev, skip_prev = skip_prev, max(skip_prev, take_prev + money)
    return skip_prev
```

这里 `skip_prev` 表示扫过当前房屋之后的最优，`take_prev` 是「上一间没被选进最新方案」时手里的旧最优，用来加上当前金额。

### 复杂度

时间 `O(n)`，滚动变量空间 `O(1)`。记忆化空间 `O(n)`。

### 边界

空数组返回 0。只有一间，返回那一间，不能去读 `i+2` 越界。相邻约束的反例：`[2, 100, 3]` 若写成「隔一间无条件相加」会得到 `2+3=5`，漏掉中间的 100。

## 打家劫舍II

### 来源

LeetCode 213。房屋围成圈，第一间和最后一间也相邻。原文只有出处。

### 描述

仍是不能偷相邻。`[4, 1, 2, 9]` 围成圈时，4 和 9 也挨在一起。不偷最后一间，线性问题是 `[4, 1, 2]`，最优 `4+2 = 6`；不偷第一间，是 `[1, 2, 9]`。这里 2 和 9 相邻，不能一起偷，最优是 `1+9 = 10`。答案取 10。

### 思路

圈上的最优，要么不含首间，要么不含末间。两段都化成上一题，再取较大值。只有一间时两段都会变成空，要单独返回那一间。

### 代码

```python
def rob_circle(nums):
    if not nums:
        return 0
    if len(nums) == 1:
        return nums[0]

    def linear(segment):
        earlier, best = 0, 0
        for money in segment:
            earlier, best = best, max(best, earlier + money)
        return best

    return max(linear(nums[:-1]), linear(nums[1:]))
```

### 复杂度

时间 `O(n)`，空间 `O(1)`。

### 边界

两间 `[8, 3]`：不能都偷，答案 8。若把圈当成直线，`[4, 1, 2, 9]` 会偷到 `4+9 = 13`，首尾却挨着，不合法。

## 打家劫舍III

### 来源

LeetCode 337。房屋是二叉树，父子不能同时偷。原文只有出处。

### 描述

```text
    4
   / \
  1   5
     / \
    2   3
```

偷根和两个孙子：`4+2+3 = 9`。偷中间的 5 再加左边的 1 只有 6。答案 9。

### 思路

每个结点返回两个数：偷这个结点的最优，以及不偷它的最优。

- 偷它：自己的钱加上左右孩子「不偷」的值。
- 不偷它：左右孩子各自取两种选择里的较大者，再相加。

### 走一遍

叶子 2：偷 2，不偷 0。叶子 3 同样。结点 5：偷 `5+0+0 = 5`，不偷 `max(2,0)+max(3,0) = 5`。叶子 1：偷 1，不偷 0。根：偷 `4 + 0 + 5 = 9`（左孩子不偷是 0，右孩子不偷是 5），不偷是 `max(1,0)+max(5,5) = 6`。总答案 `max(9, 6) = 9`。

### 代码

```python
def rob_tree(root):
    def pair(node):
        if node is None:
            return 0, 0
        left_take, left_skip = pair(node.left)
        right_take, right_skip = pair(node.right)
        take = node.val + left_skip + right_skip
        skip = max(left_take, left_skip) + max(right_take, right_skip)
        return take, skip

    return max(pair(root))
```

### 复杂度

每个结点访问一次，时间 `O(n)`，递归栈 `O(高度)`。

### 边界

空树返回 0。只有根：答案就是根的金额。若「不偷孩子」误写成 0 而不是孩子的 `skip`，孙子的钱会丢。

## 卖出后要歇一天的股票买卖

### 来源

LeetCode 309。卖出后要冷冻一天才能再买。原文标题写成「冻结」，题面是冷冻期。

### 描述

已知每天股价，多次买卖，手里最多持有一股。卖出的次日不能买。

`[1, 4, 2, 3]`。买 1 卖 4，利润 3；卖出次日是 2，不能当天再买，后面的 `2 → 3` 接不上。只做 `2 → 3` 利润只有 1。答案 3。若没有冷冻，`1→4` 再 `2→3` 可以是 4，这就是冷冻真正起作用的反例。

### 思路

三个状态：

- `hold`：手里有股
- `free`：空手，而且今天可以买
- `cool`：今天刚卖掉，明天才能进入 `free`

转移：今天可以继续持有，或从 `free` 买入；`free` 可以由昨天的 `free` 或昨天的 `cool` 过来；`cool` 只能是昨天持有、今天卖出。

### 走一遍

第一天买入记在 `hold = -1`，`free = 0`，`cool = 0`。

- 价格 4：`hold` 仍是 -1（用空手去买要价 4，更亏），`free` 仍是 0，卖出得到 `cool = 3`。
- 价格 2：`free` 还是 0，买入并不比继续持有更好，`hold` 保持 -1。昨天的 `cool` 解冻，`free` 变成 3。今天若卖掉旧仓，`cool = 1`，不如已经解冻的 3。
- 价格 3：可以用解冻的 3 买入，`hold = 0`；`free` 保持 3；卖掉第一天的股票得到 `cool = 2`。答案 `max(3, 2) = 3`。

### 代码

```python
def max_profit_cooldown(prices):
    if not prices:
        return 0
    hold = -prices[0]
    free = 0
    cool = 0
    for price in prices[1:]:
        new_hold = max(hold, free - price)
        new_free = max(free, cool)
        new_cool = hold + price
        hold, free, cool = new_hold, new_free, new_cool
    return max(free, cool)
```

### 复杂度

时间 `O(n)`，空间 `O(1)`。

### 边界

空数组或单日：无法完成一买一卖，利润 0。单调下跌：最好一笔都不做，不能返回负数。

## 0-1背包问题

### 描述

容量 `C = 6`。三件物品重量 `[2, 3, 4]`，价值 `[3, 7, 8]`，每件最多放一次。问最大价值。

### 解答

每件放或不放，子集有 `2^n` 个，再检查重量，大约 `O(n·2^n)`。`n` 一大就不可用。

### 贪心算法

按价值/重量：杯子似的第二件约 `7/3 ≈ 2.33`，第三件是 2，第一件是 1.5。先拿第二件再拿第一件，价值 10，剩余容量 1。真正的最优是第一件加第三件，`3+8 = 11`，重量刚好 6。贪心这里只得到 10。

### 思考

`F(i, c)`：在前 `i` 件里、容量不超过 `c` 的最大价值。

`F(i, c) = max(F(i-1, c), v[i] + F(i-1, c-w[i]))`，后者仅当 `c >= w[i]`。

一件物品两种结局：留下容量给前面的物品，或者占掉 `w[i]` 再拿走 `v[i]`。

### 记忆化搜索

```python
def knapsack_memo(weight, value, capacity):
    memo = {}

    def search(index, room):
        if index < 0 or room <= 0:
            return 0
        key = (index, room)
        if key in memo:
            return memo[key]
        skip = search(index - 1, room)
        take = 0
        if room >= weight[index]:
            take = value[index] + search(index - 1, room - weight[index])
        memo[key] = max(skip, take)
        return memo[key]

    return search(len(weight) - 1, capacity)
```

### 动态规划

行是物品，列是容量 0 到 6。

| 物品 | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
| ---- | - | - | - | - | - | - | - |
| 重量2价值3 | 0 | 0 | 3 | 3 | 3 | 3 | 3 |
| 重量3价值7 | 0 | 0 | 3 | 7 | 7 | 10 | 10 |
| 重量4价值8 | 0 | 0 | 3 | 7 | 8 | 10 | 11 |

容量 6 的 11 来自 `8 + 上一行容量 2 的 3`。

```python
def knapsack_table(weight, value, capacity):
    n = len(weight)
    dp = [[0] * (capacity + 1) for _ in range(n + 1)]
    for i in range(1, n + 1):
        for c in range(capacity + 1):
            dp[i][c] = dp[i - 1][c]
            if c >= weight[i - 1]:
                dp[i][c] = max(
                    dp[i][c],
                    value[i - 1] + dp[i - 1][c - weight[i - 1]],
                )
    return dp
```

下标要和价值对齐：第 `i` 行用 `value[i-1]`，不能把重量误当成价值填进第一行。

### 优化

第 `i` 行只依赖第 `i-1` 行，空间可以是 `O(C)`。压缩成一行时，容量必须从大到小更新，否则左边刚写下的「已放入当前物品」会被再次加进来。

```python
def knapsack_roll(weight, value, capacity):
    dp = [0] * (capacity + 1)
    for i, w in enumerate(weight):
        for c in range(capacity, w - 1, -1):
            dp[c] = max(dp[c], value[i] + dp[c - w])
    return dp
```

时间仍是 `O(n·C)`。两行滚动是 `O(C)` 空间的另一种写法；一行就够用。

### 背包问题具体解

用整张表倒推。从 `dp[3][6] = 11` 看上一行同列是 10，不相等，说明最后一件放了，容量减 4 到 2。`dp[2][2] = 3` 等于 `dp[1][2]`，第二件没放。`dp[1][2] = 3` 大于 `dp[0][2] = 0`，第一件放了。选中下标 0 和 2。

若某个容量上「放」和「不放」价值相同，严格大于才记为放入，倒推会得到其中一种最优，不一定是唯一方案。

### 复杂度

见上面两段。`C` 很大而 `n` 很小（比如 `n <= 20`）时，枚举子集可能更合适。

### 边界

容量 0 或物品为空：价值 0。单件超重：那一列始终抄「不放」。

## 最长上升子序列

### 来源

LeetCode 300。上升指严格变大。子序列可以不连续，但要保持原来的相对顺序。长度的最大值唯一，具体序列可以有好几条。

### 描述

`[4, 1, 5, 2, 6, 3]` 的一条最长上升子序列是 `1, 2, 6` 或 `1, 2, 3`，长度 3。`4, 5, 6` 也是 3。

### 思考

`tail[i]` 表示以第 `i` 个数结尾的最长上升子序列长度。`tail[i] = max(tail[j] + 1)`，其中 `j < i` 且 `nums[j] < nums[i]`；若没有这样的 `j`，长度就是 1。

暴力枚举所有子序列是 `O(n·2^n)`。

### 走一遍

| 数 | 4 | 1 | 5 | 2 | 6 | 3 |
| 长度 | 1 | 1 | 2 | 2 | 3 | 3 |

5 接在 4 或 1 后面变成 2；6 接在 5 后面变成 3；3 接在 2 后面变成 3。全局最大是 3。

### 代码

```python
def lis_length(nums):
    n = len(nums)
    if n == 0:
        return 0
    tail = [1] * n
    i = 1
    while i < n:
        for j in range(i):
            if nums[j] < nums[i]:
                tail[i] = max(tail[i], tail[j] + 1)
        i += 1
    return max(tail)
```

顺着 `tail` 从最大值往回减，可以还原出一条具体序列：在 `[4, 1, 5, 2, 6, 3]` 里从末尾的 3（长度 3）找到 2（长度 2）再找到 1（长度 1）。

### 复杂度

双重循环时间 `O(n^2)`，空间 `O(n)`。另有基于「当前各长度的最小结尾」的 `O(n log n)` 做法，这一课先把平方的填表写稳。

### 边界

空数组长度 0。严格下降 `[9, 8, 7]` 每一项都是 1，答案 1，不能把相等或下降也接上。若题目改成非严格上升，比较符才改成 `<=`。

## 摆动序列

### 来源

LeetCode 376。原文的「思考」是空的。

### 描述

相邻差要正负交替，差为 0 不算交替。可以删掉一些元素。少于两个元素时，序列本身算摆动。

`[3, 3, 5, 5, 4]` 删掉重复后是 `3, 5, 4`，长度 3。全相等的 `[8, 8, 8]` 长度是 1，因为差全是 0。单调的 `[2, 4, 6, 8]` 最长只能留两个数。

### 思考

扫一遍，维护「以上升差结尾」和「以下降差结尾」的最长长度。

- 当前比前一个大：上升长度 = 下降长度 + 1。
- 当前比前一个小：下降长度 = 上升长度 + 1。
- 相等：两条都不延长。

这是在贪心保留最近一次转折，等价于线性动态规划。

### 走一遍

`[3, 3, 5, 5, 4]`，`up = down = 1`。

- 第二个 3 相等，不变。
- 5 比 3 大，`up = 1 + 1 = 2`。
- 第二个 5 相等。
- 4 比 5 小，`down = 2 + 1 = 3`。

答案 3。

### 代码

```python
def wiggle_length(nums):
    n = len(nums)
    if n < 2:
        return n
    up = down = 1
    i = 1
    while i < n:
        if nums[i] > nums[i - 1]:
            up = down + 1
        elif nums[i] < nums[i - 1]:
            down = up + 1
        i += 1
    return max(up, down)
```

### 复杂度

时间 `O(n)`，空间 `O(1)`。

### 边界

`[]` 返回 0，单元素返回 1。`[1, 7, 7, 4]` 中间的平段必须跳过，否则会把 0 差当成转折，长度会多算。

## 最长公共子序列

### 来源

LeetCode 1143。子序列不必连续。没有公共部分就返回 0。

### 描述

`text1 = "mars"`，`text2 = "smart"`。公共子序列 `"mar"` 长度为 3。`"s"` 也公共，但 `"mars"` 里的 `s` 在末尾，`"smart"` 里的 `s` 在开头，没法再把 `s` 接到 `mar` 后面。

### 思考

`L[i][j]` 是两串前 `i` 个和前 `j` 个字符的最长公共子序列长度。

- 末字符相同：`L[i][j] = L[i-1][j-1] + 1`
- 不同：`L[i][j] = max(L[i-1][j], L[i][j-1])`

单源最短路里「到某点的最短距离只依赖更早的点」也是同一类最优子结构，不过那一题的转移走在图上，不在这里展开。

### 走一遍

行是 `mars`，列是 `smart`：

```text
    s m a r t
  0 0 0 0 0 0
m 0 0 1 1 1 1
a 0 0 1 2 2 2
r 0 0 1 2 3 3
s 0 1 1 2 3 3
```

右下角 3。最后一个 `s` 对 `t` 不相等，从左边或上边继承 3。

### 代码

```python
def lcs_len(a, b):
    prev = [0] * (len(b) + 1)
    for i, ca in enumerate(a, 1):
        cur = [0] * (len(b) + 1)
        for j, cb in enumerate(b, 1):
            if ca == cb:
                cur[j] = prev[j - 1] + 1
            else:
                cur[j] = max(prev[j], cur[j - 1])
        prev = cur
    return prev[-1]
```

### 复杂度

时间 `O(|a|·|b|)`，两行滚动后空间 `O(|b|)`。

### 边界

任一串为空：表的第一行第一列保持 0。这是子序列不是子串，`"ac"` 和 `"abc"` 的答案是 2，不能因为中间隔了 `b` 就判 0。

## 分割等和子集

### 来源

LeetCode 416。表面是划分，实际是 0-1 背包：能不能选出若干数，刚好装满总和的一半。这里没有「价值」，装满即可。

### 描述

元素是正整数。`[3, 1, 4, 2]` 总和 10，一半是 5。`{1, 4}` 与 `{3, 2}` 都是 5，可以。`[3, 1, 1]` 总和 5，是奇数，不可能平分。

### 思考

`F(i, c)` 表示前 `i` 个数能否凑出和 `c`。

`F(i, c) = F(i-1, c) 或 F(i-1, c - w[i])`。

### 记忆化搜索

```python
def can_partition(nums):
    total = sum(nums)
    if total % 2 == 1:
        return False
    target = total // 2
    memo = {}

    def fill(index, room):
        if room == 0:
            return True
        if room < 0 or index < 0:
            return False
        key = (index, room)
        if key not in memo:
            memo[key] = fill(index - 1, room) or fill(index - 1, room - nums[index])
        return memo[key]

    return fill(len(nums) - 1, target)
```

目标和必须用整数。在 Python 3 里把总和除以 2 若得到浮点，后面和整数下标比较会永远对不上。

### 走一遍

目标和 5。布尔数组初始只有和 0 为真。

- 放入 3：`dp[3] = 真`
- 放入 1：`dp[4]`、`dp[1]` 为真
- 放入 4：`dp[4+1]`、`dp[4+3]` 等，`dp[5]` 尚未出现；`dp[4]` 已真
- 放入 2：`dp[5] = dp[3]` 为真

所以能装满。

一维写法要从目标和往小扫，原因和背包压缩相同。

### 复杂度

时间 `O(n·总和/2)`，空间可以压到 `O(总和/2)`。

### 边界

奇数和直接假。`[0, 0]` 若题目允许 0，一半是 0，空子集就能装满，要看题面是否保证正整数；本题按正整数，单个 `[1]` 是假。

## 零钱兑换

### 来源

LeetCode 322。硬币无限枚。凑不出返回 -1。原文「代码」一节是空的。

### 描述

硬币 `[2, 4]`，金额 6。`2+2+2` 或 `2+4` 都是 3 枚？`2+4` 是 2 枚。最少 2 枚。硬币 `[3]`、金额 2，凑不出，返回 -1。金额 0 返回 0。

### 思路

`dp[x]` 是凑出金额 `x` 的最少枚数。`dp[0] = 0`。对每枚硬币 `c`，`dp[x] = min(dp[x], dp[x-c] + 1)`。这是完全背包，内层金额要从小到大，好让同一枚硬币用多次。

### 走一遍

金额 0 到 6，初始除 0 外设成一个够大的哨兵（7）。

- 硬币 2：`dp = [0, 哨兵, 1, 哨兵, 2, 哨兵, 3]`
- 硬币 4：`dp[4] = min(2, dp[0]+1) = 1`，`dp[6] = min(3, dp[2]+1) = 2`

答案 2。

### 代码

```python
def coin_change(coins, amount):
    huge = amount + 1
    need = [huge] * (amount + 1)
    need[0] = 0
    for money in range(1, amount + 1):
        for coin in coins:
            if coin <= money:
                need[money] = min(need[money], need[money - coin] + 1)
    return need[amount] if need[amount] <= amount else -1
```

### 复杂度

时间 `O(金额 × 硬币种数)`，空间 `O(金额)`。

### 边界

金额 0：即使硬币列表很怪，也是 0 枚。硬币面额大于金额：内层直接跳过，不会出现负下标。哨兵若用 0 初始化，`min` 会把一切收成 0。

## 组合总和

### 来源

LeetCode 377，组合总和 IV。顺序不同算不同方案。原文只有题面。

### 描述

`nums = [2, 3]`，`target = 5`。有序方案是 `(2, 3)` 和 `(3, 2)`，共 2 种。`(2, 2, 1)` 里没有 1，不算。

### 思路

`dp[t]` 是凑出 `t` 的方案数，`dp[0] = 1`（什么都不拿，一种空方案）。枚举最后一步放哪一个数：`dp[t] += dp[t - num]`。外层是目标和、内层是数字时，不同顺序会分成不同的「最后一步」，正好符合「顺序不同算不同」。若把循环对调，就变成组合而不是排列。

### 走一遍

`dp[0] = 1`。

- 2：只来自 `dp[0]`，方案 1，即 `(2)`
- 3：来自 `dp[0]` 放 3，方案 1
- 4：来自 `dp[2]` 放 2，方案 1，即 `(2, 2)`
- 5：`dp[3]` 放 2，加上 `dp[2]` 放 3，方案 2

### 代码

```python
def combination_count(nums, target):
    ways = [0] * (target + 1)
    ways[0] = 1
    for total in range(1, target + 1):
        for num in nums:
            if num <= total:
                ways[total] += ways[total - num]
    return ways[target]
```

### 复杂度

时间 `O(target × 数字个数)`，空间 `O(target)`。

### 边界

`target = 0`：空方案 1 种。数字里若有 0，上面的循环会无限把 `ways[t]` 加到自己身上，题面给出的是正整数且无重复，不要把 0 放进来。

## 一和零

### 来源

LeetCode 474。原文只有题面。

### 描述

你有 `m` 个 0 和 `n` 个 1。字符串数组里每个串都要原样拼出，每个串最多用一次，0 和 1 也不能拆给两个串共用。问最多能拼几个串。

`strs = ["01", "11", "0"]`，`m = 2`，`n = 1`。`"11"` 要两个 1，配额不够。`"01"` 加上 `"0"` 用掉两个 0 和一个 1，能拼出 2 个串。答案 2。

### 思路

每个串是一件物品，成本是二维的 `(零的个数, 一的个数)`，价值是 1。0-1 背包，容量从大到小，避免一个串被选两次。

### 走一遍

`dp[z][o]` 初始全 0，表示用了不超过 `z` 个 0、不超过 `o` 个 1 时最多几个串。

- `"01"` 成本 (1, 1)：`dp[1][1] = 1`，多出来的 0 让 `dp[2][1] = 1`。
- `"11"` 要 2 个 1，`n` 只有 1，这一件放不进。
- `"0"` 成本 (1, 0)：`dp[1][0] = 1`。容量 (2, 1) 可以在已经拼出 `"01"` 的状态上再加它：`dp[2][1] = max(1, dp[1][1] + 1) = 2`。

### 代码

```python
def ones_and_zeroes(words, zeros, ones):
    dp = [[0] * (ones + 1) for _ in range(zeros + 1)]
    for word in words:
        z = word.count("0")
        o = len(word) - z
        for i in range(zeros, z - 1, -1):
            for j in range(ones, o - 1, -1):
                dp[i][j] = max(dp[i][j], dp[i - z][j - o] + 1)
    return dp[zeros][ones]
```

### 复杂度

时间 `O(串数 × m × n × 平均串长)`，空间 `O(m·n)`。数 0 的那一步把平均串长乘了进去。

### 边界

`m = n = 0`：只有空串能被拼，普通的 `"0"` 或 `"1"` 都不行，答案 0。某个串的 0 已经超过 `m`，内层范围是空的，自动跳过。

## 单词拆分

### 来源

LeetCode 139。字典里的词可以重复用。原文只有题面。

### 描述

问字符串能不能切成若干段，每段都在字典里。

`s = "pineapple"`，字典 `["pine", "apple"]`，切成两段，真。`s = "pinecone"`，同一字典，`"cone"` 不在字典里，假。

### 思路

`dp[i]` 表示前 `i` 个字符能否切完。`dp[0]` 为真。若存在 `j < i` 使 `dp[j]` 为真，且 `s[j:i]` 在字典里，则 `dp[i]` 为真。

### 走一遍

`"pineapple"` 长度 9。

- 长度 4：`"pine"` 在字典，`dp[4] = 真`
- 长度 9：`"apple"` 等于 `s[4:9]`，且 `dp[4]` 为真，所以真
- `"pinecone"` 长度 8：前 4 个真，`s[4:8] = "cone"` 不在字典，没有别的切点，假

### 代码

```python
def can_break(text, dictionary):
    vocab = set(dictionary)
    ok = [False] * (len(text) + 1)
    ok[0] = True
    for end in range(1, len(text) + 1):
        for start in range(end):
            if ok[start] and text[start:end] in vocab:
                ok[end] = True
                break
    return ok[-1]
```

### 复杂度

两重循环再加切片，时间大约 `O(n^3)`（哈希集合判定平均看作线性于子串长度），空间 `O(n + 词典)`。

### 边界

空串：`ok[0]` 为真，但题面通常保证非空。字典里有空字符串时，切片会让同一个 `end` 反复成功，应先把空词删掉。`"a"` 对字典 `["b"]` 为假，不能因为长度相等就返回真。

## 目标和

### 来源

LeetCode 494。原文只有题面。

### 描述

非负数组，每个数前面加 `+` 或 `-`，使结果等于目标 `S`，问几种加法。

`[1, 2, 3]`，`S = 0`。

- `+1 +2 -3 = 0`
- `-1 -2 +3 = 0`

共 2 种。`+1 -2 +3 = 2`，不是 0。

### 思路

设正号部分之和为 `P`，负号部分之和为 `N`。`P + N = 总和`，`P - N = S`，所以 `2P = 总和 + S`，`P` 必须是整数。问题变成：有多少个子集的和等于 `(总和 + S) / 2`。每个数仍然只能进正号组一次，是 0-1 的计数背包。

### 走一遍

总和 6，目标子集和 3。`dp[0] = 1`。

- 放 1：`dp[1] = 1`
- 放 2：`dp[3] = 1`，`dp[2] = 1`
- 放 3：`dp[3] += dp[0]` 变成 2

两种子集是 `{3}` 和 `{1, 2}`，对应上面两种符号。

### 代码

```python
def target_ways(nums, goal):
    total = sum(nums)
    if goal > total or (total + goal) % 2 == 1 or goal < 0:
        return 0
    half = (total + goal) // 2
    ways = [0] * (half + 1)
    ways[0] = 1
    for num in nums:
        for s in range(half, num - 1, -1):
            ways[s] += ways[s - num]
    return ways[half]
```

数组从大到小更新，保证每个数只用一次。若从小到大，同一个数会被重复累加，变成完全背包的计数。

### 复杂度

时间 `O(n × (总和+S)/2)`，空间 `O((总和+S)/2)`。

### 边界

`S` 大于总和，或 `总和 + S` 是奇数：0 种。`S` 为负时，正负号对调后和 `-S` 的方案数相同；上面的代码按题面非负目标写成直接返回 0 的那一版，若要支持负数，先取绝对值再套同一公式。`[0]`、目标 0：`+0` 和 `-0` 在数值上一样，但符号不同，计数是 2，子集和公式会把 0 的两种放法算进去（`ways[0]` 在放入 0 时再加一次）。这和「0 既可加也可减」一致。

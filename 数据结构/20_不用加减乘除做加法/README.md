# 不用加减乘除做加法

## 题目描述

写一个函数，求两个整数的和。函数体里不能使用加、减、乘、除。

## 思考

不能用四则运算时，改用位运算，把「相加」拆成两件事：

1. 不考虑进位，逐位相加。相同得 0，不同得 1，这就是异或。
2. 只有两位都是 1 才会进位。先按位与，再左移一位，就是进位值。

然后把「异或结果」和「进位」再当作两个新的加数，重复上面两步，直到进位变成 0。

Python 的整数没有固定字长，负数的高位会无限延伸。每一步都和 `0xFFFFFFFF` 做与，把中间结果限制在 32 位。最后若最高位是 1，再还原成 Python 里的负数。

## 演算示例

计算 `13 + 9`，不用加号。13 是 `1101`，9 是 `1001`。

1. 异或：`1101 ^ 1001 = 0100`，也就是 4。这是不进位的和。
2. 进位：`1101 & 1001 = 1001`，左移一位得到 `10010`，也就是 18。
3. 再合并：`0100 ^ 10010 = 10110`，即 22。这一步按位与是 0，没有新的进位。

结果是 22。

再看负数 `-3 + 5`。截成 32 位后，-3 的补码末尾是 `...1101`。和 5（`0101`）异或得到末尾 `1000`，进位左移后继续合并，最终落到 2。

## 代码

```python
class Solution:
    def Add(self, num1, num2):
        mask = 0xFFFFFFFF
        while num2 & mask:
            carry = (num1 & num2) << 1
            num1 = (num1 ^ num2) & mask
            num2 = carry & mask
        # 32 位里最高位为 1 时，转回负数
        if num1 <= 0x7FFFFFFF:
            return num1
        return ~(num1 ^ mask)


if __name__ == "__main__":
    solver = Solution()
    assert solver.Add(13, 9) == 22
    assert solver.Add(-3, 5) == 2
    assert solver.Add(-8, -6) == -14
    assert solver.Add(0, 0) == 0
    assert solver.Add(0, -4) == -4
    print(solver.Add(13, 9))
```

## 复杂度

进位每次至少左移一位，32 位以内循环次数有上界，时间 `O(1)`，空间 `O(1)`。

## 反例与边界

- `0 + 0` 进位一开始就是 0，循环不执行，结果是 0。
- `-8 + -6` 必须得到 -14。若忘记把 32 位补码还原成负数，会返回一个接近 `2^32` 的大正数。
- 只做一次异或就返回，会丢掉进位。`13 ^ 9 = 4`，不是 22。

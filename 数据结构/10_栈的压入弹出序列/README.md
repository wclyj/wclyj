# 栈的压入弹出序列

## 题目描述

给出两个等长的整数序列。第一个是某个栈的压入顺序，第二个是待检查的弹出顺序。栈中数字互不相同。判断第二个序列有没有可能是这个压入过程对应的一种弹出序列。可以在压入的间隙随时弹出。

## 思路

用一个辅助栈按压入顺序模拟。每压入一个数，就看栈顶是不是当前该弹出的数；是的话立刻弹出，并继续看新的栈顶，因为可能连续弹出好几次。压入序列用完后，辅助栈必须是空的。还剩元素，说明有的数字被压在了不该压住它的数下面，这个弹出序列做不到。

## 演算示例

压入顺序用 `[2, 5, 7, 9]`。

可行的弹出序列 `[5, 9, 7, 2]`：

1. 压入 2。栈：`[2]`。栈顶不是 5。
2. 压入 5。栈：`[2, 5]`。栈顶等于 5，弹出。栈：`[2]`。
3. 压入 7。栈：`[2, 7]`。栈顶不是 9。
4. 压入 9。栈：`[2, 7, 9]`。栈顶等于 9，弹出。栈顶接着等于 7，再弹出。栈：`[2]`。
5. 栈顶等于最后的 2，弹出。栈空，返回真。

不可能的弹出序列 `[5, 9, 2, 7]`，这组应当返回假：

1. 压入 2，再压入 5，立刻弹出 5。栈：`[2]`。
2. 压入 7，再压入 9，弹出 9。栈：`[2, 7]`。
3. 下一个要弹出的是 2，但栈顶是 7。7 还没弹出，2 出不来。
4. 后面不再有新的压入，循环结束时栈里仍是 `[2, 7]`，不是空栈，判定为假。

## 代码

```python
class Solution:
    def IsPopOrder(self, push_order, pop_order):
        # 用辅助栈模拟压入，并在栈顶匹配时立刻弹出
        if not push_order or len(push_order) != len(pop_order):
            return False
        stack = []
        pop_index = 0
        for value in push_order:
            stack.append(value)
            while stack and stack[-1] == pop_order[pop_index]:
                stack.pop()
                pop_index += 1
        return len(stack) == 0


if __name__ == "__main__":
    solver = Solution()
    assert solver.IsPopOrder([2, 5, 7, 9], [5, 9, 7, 2]) is True
    # 2 被 7 压住，却要先于 7 弹出
    assert solver.IsPopOrder([2, 5, 7, 9], [5, 9, 2, 7]) is False
    assert solver.IsPopOrder([], []) is False
    assert solver.IsPopOrder([1, 2], [1]) is False
    print(solver.IsPopOrder([2, 5, 7, 9], [5, 9, 2, 7]))
```

## 复杂度

每个元素最多压入一次、弹出一次，时间 `O(n)`，辅助栈空间 `O(n)`。

## 反例与边界

- `[5, 9, 2, 7]` 相对压入顺序 `[2, 5, 7, 9]` 必须返回假。2 先进栈，7 后进栈，在 7 弹出之前不可能先弹出 2。
- 两个序列长度不同，或者都是空序列，直接返回假。空序列不是一次合法的压入弹出过程。
- 数字若允许重复，仅靠栈顶相等无法区分是哪一次压入，本题前提是全部互异。

# Rust 入门取向

Rust 把内存安全尽量放在编译期解决。每个值有一个所有者；赋值或传参通常把所有权移走，原来的名字不能再使用。想共享读取时用借用（`&T`），想改别人拥有的值时用可变借用（`&mut T`）。同一时刻，要么有多个只读借用，要么只有一个可变借用。

所有权配合类型，使大量程序不必写垃圾回收，也不必手动 `free`。编译器拒绝悬空引用和数据竞争，代价是初学时要看懂借用检查器的报错。

一个很小的例子：函数拿走一个 `String`，返回它的长度，调用处不能再碰原来的变量。

```rust
fn chars_of(text: String) -> usize {
    text.chars().count()
}

fn main() {
    let name = String::from("杭州");
    let n = chars_of(name);
    println!("{n}");
}
```

`"杭州"` 有两个 Unicode 标量，`chars().count()` 得到 2。若改成按字节数 `len()`，会得到这两个汉字的 UTF-8 字节长度 6，和「几个字」不是一回事。

常见坑：把 `name` 传进 `chars_of` 之后再 `println!("{name}")`。所有权已经移进函数，`name` 失效，编译直接失败。若函数只是查看内容，参数应写成 `text: &str`，调用时传 `&name`，这样 `name` 还留在调用者手里。另一个相关坑是在已经存在不可变借用时再取可变借用，编译器同样会拒绝，而不是留到运行时才崩。
